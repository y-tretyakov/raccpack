# A1.1 — Интеграция age (passphrase), zeroize материала ключа

**Фаза:** A1 — Stash (age)  
**Веха:** Alpha → 0.2.x–0.3.x  
**Зависимости:** M4.2 (den paths), M1.2 (Error)  
**Параллельность:** Dev + Test

---

## 1. Цель

Подключить **age** (passphrase identity) как backend шифрования секретов:

- encrypt bytes → `.age` file;
- decrypt только для внутренних тестов (public API stash **не** обязан уметь decrypt в v1 CLI);
- **zeroize** passphrase / key material сразу после use;
- никакого raw passphrase в `Error` / logs / Display.

Без facade, без удаления файлов, без den place — только crypto-примитив.

---

## 2. Контекст

Vision: шифрование секретов — **age** (passphrase или recipients); 7z не ядро доверия.

Facade:

```rust
pub enum AgeIdentity {
    Passphrase(String),      // на практике Zeroizing<String> / SecretString
    Recipients(Vec<String>), // public age recipients — можно заготовить, MVP = passphrase only
}
```

Для A1.1: **только Passphrase**. Recipients — stub или later.

---

## 3. Модульность и файлы

```text
crates/raccpack-core/
  Cargo.toml                 # + age, zeroize, secrecy (или zeroize only)
  src/
    archive/
      mod.rs                 # pub mod age_vault;
      age_vault.rs           # NEW: encrypt_file, encrypt_bytes, AgeVaultError mapping
    error.rs                 # variant(s) for encrypt failures — без утечки passphrase
```

**Не** класть age-логику в `app/` или `cli`.

### 3.1. Зависимости (core)

```toml
[dependencies]
age = { version = "0.10", features = ["armor"] }  # или актуальный 0.x; зафиксировать в спеке при реализации
zeroize = { version = "1", features = ["derive"] }
# secrecy = "0.8"  # опционально SecretString; можно Zeroizing<String>
```

Выбрать **одну** обёртку для passphrase в памяти: `zeroize::Zeroizing<String>` или `secrecy::SecretString`. В public facade API можно принять `AgeIdentity`, внутри сразу обернуть и zeroize на drop.

### 3.2. Публичный API модуля (minimal)

```rust
// archive/age_vault.rs

use std::path::Path;
use zeroize::Zeroizing;

/// Encrypt plaintext bytes to an age file (scrypt passphrase).
///
/// - Overwrites `output` if exists.
/// - Passphrase is zeroized after the call (caller should also wrap).
/// - Never returns or logs the passphrase.
pub fn encrypt_bytes_to_file(
    plaintext: &[u8],
    output: &Path,
    passphrase: &Zeroizing<String>,
) -> Result<(), Error>;

/// Encrypt a single source file into an age archive file.
pub fn encrypt_file_to_age(
    source: &Path,
    output: &Path,
    passphrase: &Zeroizing<String>,
) -> Result<u64 /* bytes_read */, Error>;

/// Test-only / internal: decrypt age file with passphrase.
/// Not exported from lib root in production API surface if avoidable;
/// available under `#[cfg(test)]` or `feature = "age-decrypt-tests"`.
#[cfg(any(test, feature = "age-decrypt"))]
pub fn decrypt_file_from_age(
    source: &Path,
    passphrase: &Zeroizing<String>,
) -> Result<Vec<u8>, Error>;
```

Ошибки: map age errors → `Error::Encrypt { message }` / `Error::Io` **без** включения passphrase в message.

## 4. Поведение и инварианты

| Правило | Деталь |
|---------|--------|
| Zeroize | `Zeroizing` / explicit `zeroize()` после encrypt; не хранить копию в struct надолго |
| Armor | binary age format OK; ASCII armor optional (`features = ["armor"]`) — **зафиксировать: binary** для размера |
| Passphrase strength | core **не** навязывает политику длины в A1.1 (CLI может warn); пустая строка → Error |
| Atomic write | писать в `output.tmp` + rename, либо документировать что caller использует staging |
| Thread-safety | функция синхронная; не держать passphrase в static |

---

## 5. Тесты (обязательные)

Файл: `crates/raccpack-core/src/archive/age_vault.rs` `#[cfg(test)]` и/или `tests/age_vault.rs`.

1. **Roundtrip:** encrypt_bytes → decrypt → equal plaintext.
2. **Wrong passphrase:** decrypt fails.
3. **Empty passphrase:** encrypt returns Error.
4. **File roundtrip:** tempfile with known content → age → decrypt matches.
5. **No passphrase in error Display:** encrypt fail path (e.g. bad output path) — `format!("{e}")` does not contain the passphrase string used.
6. **Overwrite:** second encrypt to same path succeeds.
7. **Zeroize smoke:** (optional) use a custom type that counts zeroize calls if practical; иначе документировать reliance on `Zeroizing` Drop.

Команда:

```bash
cargo test -p raccpack-core age_vault
```
