# A1.2 — Manifest записей stash без raw; удаление источников в Commit

**Фаза:** A1 — Stash (age)  
**Зависимости:** A1.1 (encrypt), M3.1/M3.2 (findings / scan_secrets), M1.4 walk  
**Параллельность:** Dev + Test

---

## 1. Цель

1. **Выбрать** файлы для stash (по dig-результату или повторному scan, `min_risk`).
2. Собрать **manifest entries** (path, risk, size) — **без raw**.
3. Упаковать выбранные файлы в **один** age-архив (batch): формат batch = tar внутри age **или** age на каждый файл + outer tar — **зафиксировать один вариант**.
4. API **удаления источников** после успешного encrypt (только когда caller просит Commit-семантику).

Без facade `stash` и без den `place` — внутренние операции, которые вызовет A1.3.

---

## 2. Выбор формата batch (решение)

**Рекомендация (зафиксировать в реализации и wiki):**

```text
plaintext batch = tar (ustar) of relative file paths
                 → age-encrypt whole tar → single `.age` file
```

Альтернатива (хуже для atomicity): N отдельных `.age` + sidecar index.

В manifest JSON (facade later) — список original paths + risk + size, без содержимого.

## 4. Алгоритмы

### 4.1. Select

```text
if only_files is Some:
  validate each exists under target (path containment)
  risk from match_filename / optional content; filter min_risk
else:
  run scan_secrets(target) or map from prior dig
  filter risk >= min_risk
  only files (not dirs)
sort by path
```

Path containment: каждый file must be under `target` (after canonicalize/normalize). Иначе Error.

### 4.2. write_stash_age

```text
1. if entries empty → Error::StashEmpty or Ok empty? → Error "nothing to stash"
2. build tar in memory or tempfile:
     for e in entries:
       append file at e.relative_path (no absolute, no ..)
3. encrypt tar bytes → output_age (age_vault)
4. build manifest from entries
5. return stats
```

При ошибке encrypt — не удалять sources; partial output_age удалить.

### 4.3. remove_stash_sources

```text
for entry in entries:
  remove_file(original_path)?
count++
```

Только files; не трогать dirs.  
**Не** вызывать из DryRun path.

## 5. Тесты

1. **select** fixture: `.env` High, `notes.txt` none → only `.env`.
2. **min_risk Critical** filters High-only env if only High.
3. **only_files** limits set; path outside target → Error.
4. **write_stash_age** creates file; decrypt+untar restores content (test feature).
5. Manifest len == files_archived; no raw in serde JSON of manifest.
6. **remove_stash_sources** deletes files; second call fails/not found.
7. Empty select → clear Error.
8. relative_path has no `..` components.
