**Фаза:** A1 — Stash (age)  
**Зависимости:** A1.1, A1.2, M4.2 (`ensure_den`, naming), M2.3 (`AppContext`, `RunMode`, `ProgressSink`)  
**Параллельность:** Dev + Test

---

## 1. Цель

Публичный use-case **`stash`** по facade-документу:

- DryRun: посчитать список и **ожидаемый** путь `.age`, ничего не писать/не удалять;
- Commit: select → encrypt to staging → place under `den/secrets/yyyy/mm/` → optional remove sources;
- Progress events;
- `StashResult` без raw secrets.

## 2. Facade API (канон)

Из `raccpack-facade-and-den.md` §5 — **совпадает 1:1 с реализацией**:

```rust
pub struct StashOptions {
    pub target: PathBuf,
    pub only_files: Option<Vec<PathBuf>>,
    pub min_risk: SensitiveRisk,      // default High
    pub remove_sources: bool,         // only effective in Commit
    pub batch_id: Option<String>,
}

pub enum AgeIdentity {
    Passphrase(String),               // wrapped to Zeroizing immediately inside
    Recipients(Vec<String>),          // A1: return Error::Unsupported if used
}

pub struct StashResult {
    pub archive_path: PathBuf,        // absolute final (or expected in DryRun)
    pub files_archived: usize,
    pub bytes_archived: u64,
    pub removed_sources: usize,       // 0 in DryRun
    pub dry_run: bool,
    pub manifest: Vec<StashManifestEntry>,
}

pub struct StashManifestEntry {
    pub original_path: PathBuf,
    pub risk: SensitiveRisk,
    pub size_bytes: u64,
}

pub fn stash(
    ctx: &AppContext,
    opts: &StashOptions,
    identity: &AgeIdentity,
    progress: &mut dyn ProgressSink,
) -> Result<StashResult, Error>;
```

## 4. Алгоритм `stash`

```text
1. progress: phase=stash, 0%, "selecting files"
2. identity: only Passphrase; empty → Error; wrap Zeroizing
3. select_files_for_stash(...)
4. if empty → Error (or Ok with 0 files? → Error "no files matched min_risk")
5. slug/ts from target name + now (or batch_id in name if provided)
6. expected final path under ctx.paths.den_dir

7. if DryRun:
     return StashResult {
       archive_path: expected,
       files_archived: entries.len(),
       bytes_archived: sum sizes,
       removed_sources: 0,
       dry_run: true,
       manifest: from entries,
     }

8. ensure_den(den)
9. progress: "encrypting"
10. staging = den/staging/{short_id}/secrets.age
11. write_stash_age(entries, staging, passphrase)
12. progress: "placing"
13. placed = place_secrets_archive(...)
14. removed = 0
15. if opts.remove_sources:
      progress: "removing sources"
      removed = remove_stash_sources(...)
16. zeroize passphrase (Drop)
17. progress: 100% complete
18. Ok(StashResult { archive_path: placed.absolute, ..., removed_sources: removed, dry_run: false })
```

**Fail-safe:** if encrypt fails → no remove. If place fails → leave staging for debug (or cleanup); no remove. If remove fails mid-way → return Error but age already placed (document partial state).
