# A1.4 — CLI: `racc stash` (prompt passphrase / env для CI)

**Фаза:** A1 — Stash (age)  
**Зависимости:** A1.3, existing CLI (clap Commands)  
**Параллельность:** Dev + Test

---

## 1. Цель

```bash
racc stash --project PATH --den PATH
racc stash --project PATH --den PATH --yes
racc stash --project PATH --den PATH --yes --remove-sources
racc stash --project PATH --den PATH --json
```

Passphrase:

1. Env `RACCPACK_PASSPHRASE` (CI / non-interactive) — приоритет высокий если set.
2. Иначе interactive prompt (tty) с confirmation (enter twice) — **не** echo.
3. Иначе stdin single line if piped (optional) — документировать.
4. Нет tty и нет env → Error с suggestion.

Default mode: **DryRun** (как pack). `--yes` → Commit.

        if p.is_empty() { return Err(...) }
        // remove from env optional: std::env::remove_var — document tradeoff
        return Ok(Zeroizing::new(p));

## 3. Clap

```text
racc stash [OPTIONS]

Required:
      --project <PATH>     Target project / subtree

Options:
      --den <PATH>         Den (or config paths.den_dir)
      --yes                Commit (write .age, maybe delete sources)
      --dry-run            Force dry-run
      --remove-sources     After successful encrypt, delete original files (Commit only)
      --min-risk <LEVEL>   low|medium|high|critical  (default: high)
      --only <PATH>        Repeatable: only these files (must be under project)
      --json
      --batch-id <ID>      Optional name fragment
```

Mapping:

| CLI | StashOptions / ctx |
|-----|-------------------|
| `--yes` without `--dry-run` | RunMode::Commit |
| default / `--dry-run` | DryRun |
| `--remove-sources` | remove_sources: true (ignored in DryRun) |
| `--min-risk high` | min_risk: High |
| `--only` | only_files: Some(...) |

## 4. Поток

```text
1. Parse + load config + overrides
2. mode from --yes / --dry-run
3. read_passphrase() → Zeroizing
4. AgeIdentity::Passphrase(inner.clone into identity as needed)
5. stash(&ctx, &opts, &identity, progress)
6. print human or JSON StashResult
7. drop passphrase
8. exit 0 / 1
```
