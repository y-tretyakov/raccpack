# A4.2 — Config migrate chain + `racc init`

**Фаза:** A4 — Git и DX alpha  
**Зависимости:** M1.3 config  
**Параллельность:** Dev + Test

---

## 1. Цель

1. Поле **`config_version`** в TOML + цепочка migrate `vN → vN+1`.
2. Команда **`racc init`**: создать default config (и опционально den skeleton).
3. При `load`: если version старый — migrate (in-memory и опционально rewrite file).

## 3. Config version

```toml
# config.toml
config_version = 1

[paths]
scan_root = "~/DEV/PROJS"
den_dir = "~/.raccpack/den"

[scanner]
max_depth = 6

[cleanup]
enabled_strategies = ["rust", "node", "python"]
```

```rust
pub const CURRENT_CONFIG_VERSION: u32 = 1;

pub fn migrate(raw: toml::Value) -> Result<toml::Value, ConfigError> {
    let mut v = version of raw or 0;
    while v < CURRENT_CONFIG_VERSION {
        raw = migrate_step(v, raw)?;
        v += 1;
    }
    Ok(raw)
}
```

Alpha: только version **1** (identity migrate). Цепочка готова к v2+.

Strict: unknown future version → Error «downgrade client».

## 4. `racc init` API / behavior

```rust
pub struct InitOptions {
    pub config_path: PathBuf,
    pub force: bool,           // overwrite
    pub scan_root: Option<PathBuf>,
    pub den_dir: Option<PathBuf>,
    pub ensure_den: bool,      // call ensure_den
}

pub fn init_config(opts: &InitOptions) -> Result<PathBuf, Error>;
```

Default path: XDG `~/.config/raccpack/config.toml` (same as load).

---

## 5. CLI

```text
racc init [OPTIONS]

Options:
      --config <PATH>       Where to write (default XDG)
      --force               Overwrite existing
      --scan-root <PATH>    Prefill paths.scan_root
      --den <PATH>          Prefill paths.den_dir
      --ensure-den          Create den skeleton (.den-version, README)
      --json                Print path written
```

### Примеры команд CLI

```bash
# Создать config по умолчанию (~/.config/raccpack/config.toml)
racc init

# С путями
racc init --scan-root ~/DEV/PROJS --den ~/.raccpack/den

# Перезаписать существующий
racc init --force --scan-root ~/DEV/PROJS

# Свой путь к config
racc init --config /tmp/racc-test.toml --scan-root /tmp/proj --den /tmp/den

# Создать и den
racc init --scan-root ~/DEV/PROJS --den ~/.raccpack/den --ensure-den

# JSON (путь к файлу)
racc init --json

# Затем проверить
racc sniff --root ~/DEV/PROJS
cat ~/.config/raccpack/config.toml
```

**Негативные:**

```bash
# Файл уже есть без --force → exit 1
racc init
racc init   # second time fails unless --force
```
