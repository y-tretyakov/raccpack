# A3.3 — Manifest JSON в `den/manifests/…`

**Фаза:** A3 — Raid orchestration  
**Зависимости:** A3.1, M4.2 den naming  
**Параллельность:** Dev + Test

---

## 1. Цель

После raid (успешного или частично успешного **Commit**) записать **manifest JSON**:

```text
{den}/manifests/{yyyy}/{mm}/{project_slug}__{utc_timestamp}__{short_id}.json
```

Без raw secrets. Paths артефактов — **relative to den_root**.

DryRun: **не** писать manifest.

---

## 2. Модульность и файлы

```text
src/den/
  manifest.rs        # NEW: RaidManifest, write_raid_manifest
  names.rs           # reuse slug, timestamp, short_id
  layout.rs          # ensure manifests/ dir via ensure_den
src/app/
  raid.rs            # call write after phases (move step)
```

## 3. Схема manifest (schema_version: 1)

Канон из facade §9.3 — **реализация должна совпадать**:

```json
{
  "schema_version": 1,
  "created_at": "2026-08-04T15:52:30Z",
  "project_path": "/home/user/DEV/PROJS/my-api",
  "project_slug": "my-api",
  "dry_run": false,
  "success": true,
  "stages": [
    { "name": "stash", "success": true, "message": "archived 3 files", "skipped": false },
    { "name": "rinse", "success": true, "message": "removed 2 dirs, 140MB", "skipped": false },
    { "name": "pack", "success": true, "message": "wrote pack 12MB", "skipped": false },
    { "name": "move", "success": true, "message": "finalized", "skipped": false }
  ],
  "artifacts": {
    "secrets_archive": "secrets/2026/08/my-api__20260804T155230Z__secrets.age",
    "project_pack": "packs/2026/08/my-api__20260804T155230Z.tar.zst"
  },
  "stash_manifest": [
    {
      "original_path": "/home/user/DEV/PROJS/my-api/.env",
      "risk": "High",
      "size_bytes": 412
    }
  ],
  "tool": {
    "name": "raccpack",
    "core_version": "0.1.0"
  }
}
```

### Rust types

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RaidManifest {
    pub schema_version: u32,  // 1
    pub created_at: String,   // RFC3339 UTC
    pub project_path: PathBuf,
    pub project_slug: String,
    pub dry_run: bool,
    pub success: bool,
    pub stages: Vec<RaidStageResult>,
    pub artifacts: RaidManifestArtifacts,
    pub stash_manifest: Vec<StashManifestEntry>,
    pub tool: ToolInfo,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RaidManifestArtifacts {
    #[serde(skip_serializing_if = "Option::is_none")]
    pub secrets_archive: Option<String>,  // relative
    #[serde(skip_serializing_if = "Option::is_none")]
    pub project_pack: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ToolInfo {
    pub name: String,         // "raccpack"
    pub core_version: String, // env!("CARGO_PKG_VERSION")
}
```

## 4. API

```rust
pub fn write_raid_manifest(
    den_root: &Path,
    manifest: &RaidManifest,
    timestamp: &str,
    short_id: &str,
) -> Result<PathBuf /* absolute path to json */, Error>;
```

Naming:

```text
manifests/{yyyy}/{mm}/{slug}__{timestamp}__{short_id}.json
```

`yyyy/mm` from timestamp.  
Atomic write: temp + rename under manifests/.

Integrate in raid **move** step on Commit (even if success=false but some artifacts exist — still write manifest for audit).  
Policy: **always write manifest on Commit** after phases attempt (success true or false). DryRun: skip.

---

## 5. Построение из RaidResult

```rust
pub fn manifest_from_raid_result(
    den_root: &Path,
    result: &RaidResult,
    created_at: &str,
) -> RaidManifest;
```

- relative paths: strip `den_root` prefix from archive/pack absolute paths;
- stash_manifest from `result.stash.as_ref().map(|s| s.manifest.clone()).unwrap_or_default()`;
- tool.core_version from Cargo pkg version.
