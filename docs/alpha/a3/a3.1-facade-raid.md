# A3.1 — Facade `raid`: stash → rinse → pack → move, fail-fast, `success`

**Фаза:** A3 — Raid orchestration  
**Зависимости:** A1.3 stash, A2.2 rinse, M4.3 pack, M4.2 den  
**Параллельность:** Dev + Test

---

## 1. Цель

Оркестратор use-case **`raid`**:

1. **stash** (optional) — секреты → age в den  
2. **rinse** (optional) — trash dirs  
3. **pack** (optional) — tar.zst в den  
4. **move** — finalize staging + запись путей в result (manifest — A3.3)

Fail-fast, `RaidResult.success`, DryRun/Commit через `AppContext.mode`.

---

## 2. Facade API (канон — совпадает с реализацией)

Из `raccpack-facade-and-den.md` §8:

```rust
pub struct RaidOptions {
    pub project: PathBuf,
    pub stash: StashPhaseOpts,
    pub rinse: RinsePhaseOpts,
    pub pack: PackPhaseOpts,
}

pub struct StashPhaseOpts {
    pub enabled: bool,
    pub min_risk: SensitiveRisk,
    pub remove_sources: bool,
}

pub struct RinsePhaseOpts {
    pub enabled: bool,
}

pub struct PackPhaseOpts {
    pub enabled: bool,
    pub deny_content_secrets: bool,
}

impl Default for RaidOptions {
    fn default() -> Self {
        Self {
            project: PathBuf::new(), // caller must set
            stash: StashPhaseOpts {
                enabled: true,
                min_risk: SensitiveRisk::High,
                remove_sources: true,
            },
            rinse: RinsePhaseOpts { enabled: true },
            pack: PackPhaseOpts {
                enabled: true,
                deny_content_secrets: true,
            },
        }
    }
}

pub struct RaidStageResult {
    pub name: String,       // "stash" | "rinse" | "pack" | "move"
    pub success: bool,
    pub message: String,    // без secrets
    pub skipped: bool,      // phase disabled
}

pub struct RaidResult {
    pub project_path: PathBuf,
    pub stages: Vec<RaidStageResult>,
    pub stash: Option<StashResult>,
    pub rinse: Option<RinseResult>,
    pub pack: Option<PackResult>,
    pub den_artifacts: Vec<PathBuf>,
    pub success: bool,      // true iff every enabled phase succeeded
    pub dry_run: bool,
}

/// identity required if stash.enabled; otherwise ignored.
pub fn raid(
    ctx: &AppContext,
    opts: &RaidOptions,
    identity: Option<&AgeIdentity>,
    progress: &mut dyn ProgressSink,
) -> Result<RaidResult, Error>;
```

## 4. Порядок фаз (фиксированный)

```text
1. stash   if opts.stash.enabled
2. rinse   if opts.rinse.enabled
3. pack    if opts.pack.enabled
4. move    always as logical phase when any prior Commit wrote artifacts
           (ensure paths finalized; manifest write may be A3.3 hook here)
```

### Fail-fast

- Если enabled-фаза вернула `Err` **или** внутренний `success: false` (если sub-result так маркирует) → **не** запускать следующие enabled-фазы.
- `stages` всё равно содержит: успешные/failed/skipped.
- `RaidResult.success = false`.
- Уже созданные age/pack **не** откатываются автоматически (пути в `den_artifacts` / messages).

### DryRun

- Все sub-calls с `ctx.mode = DryRun`.
- Ни secrets/, ни packs/, ни manifests/ не создаются.
- `remove_sources` не удаляет.
- Stages success=true если «план» построен без Error.

### identity

- `stash.enabled && identity is None` → Error (missing passphrase/identity).
- `stash.enabled && AgeIdentity::Recipients` → Unsupported (пока только passphrase), если A1 так решил.
- `!stash.enabled` → identity игнорируется.

## 5. Алгоритм (псевдокод)

```text
stages = []
artifacts = []
stash_r = rinse_r = pack_r = None
overall_ok = true

emit progress raid start (phase_count = enabled + 1 for move)

if stash.enabled:
  if identity missing → return Err
  match stash(ctx, StashOptions{ target: project, min_risk, remove_sources, ... }, identity, progress):
    Ok(r) → stages.push(ok "stash"); stash_r=Some(r); artifacts.push(r.archive_path) if !dry
    Err(e) → stages.push(fail "stash", e); overall_ok=false; skip rest of phases
else:
  stages.push(skipped "stash")

if overall_ok && rinse.enabled:
  match rinse(...):
    Ok(r) → stages.push(ok); rinse_r=Some(r)
    Err → fail-fast
else if rinse.enabled && !overall_ok:
  stages.push(skipped "rinse") // or "not run due to prior failure"
else:
  stages.push(skipped "rinse")

if overall_ok && pack.enabled:
  match pack(...):
    Ok(r) → stages.push(ok); pack_r=Some(r); artifacts.push(r.output) if !dry
    Err → fail-fast
else ...

# move / finalize
if overall_ok:
  ensure_den; // already done by subcalls usually
  stages.push(ok "move", "finalized")
  // A3.3: write manifest here or in dedicated step
else:
  stages.push(fail or skipped "move")

return Ok(RaidResult {
  project_path: opts.project,
  stages, stash: stash_r, rinse: rinse_r, pack: pack_r,
  den_artifacts: artifacts,
  success: overall_ok,
  dry_run: ctx.mode.is_dry_run(),
})
```

**Важно:** `raid` возвращает `Ok(RaidResult)` даже при `success: false` (частичный прогон), **кроме** ошибок preconditions (нет project, нет identity).  
Альтернатива: `Err` на fail phase — **зафиксировать: Ok + success:false** для UX/JSON (CLI exit code от success).

Рекомендация (совпадает с facade «частичный успех в stages»):

- precondition errors → `Err`
- phase failure after start → `Ok(RaidResult { success: false, ... })`

## 6. Тесты

1. All enabled DryRun: success true, no files in den.
2. All enabled Commit fixture: age + pack exist; sources removed if stash.remove_sources; node_modules gone if rinse on.
3. stash fails (bad passphrase path simulated) → rinse/pack not run; success false; stages len coherent.
4. stash.enabled=false → no identity required; rinse+pack run.
5. pack only: stash/rinse skipped.
6. den_artifacts contains expected paths on full success Commit.
7. Default RaidOptions has stash/rinse/pack enabled.
