## 3. Clap

```text
racc raid [OPTIONS]

Required:
      --project <PATH>

Options:
      --den <PATH>              den root (or config)
      --yes                     Commit all enabled phases
      --dry-run                 force dry-run
      --json

Phase toggles (default: all on):
      --no-stash
      --no-rinse
      --no-pack

Stash-related:
      --min-risk <LEVEL>        default high
      --remove-sources          default true when stash on (or flag --keep-sources to disable)
      --keep-sources            do not delete secrets after stash

Pack-related:
      --no-content-deny         pack without content secret deny
```

Passphrase: same as stash (`RACCPACK_PASSPHRASE` or prompt) **if stash enabled**.

Default mode: DryRun. `--yes` → Commit.

Exit codes:

| Code | When |
|------|------|
| 0 | `RaidResult.success == true` |
| 1 | precondition error (config, IO, missing passphrase) |
| 2 | optional: success==false after phases (policy) — **рекомендация MVP Alpha: exit 1 if !success**, or 0 with success field in JSON; **зафиксировать: exit 1 if !success** |

## 4. Поток

```text
1. parse + config
2. mode Commit iff --yes && !--dry-run
3. build RaidOptions from flags
4. if stash enabled: read_passphrase → AgeIdentity
5. progress = CliProgress or Null if json
6. result = raid(...)
7. print human summary of stages or JSON RaidResult
8. exit based on success
```

Human summary:

## 5. Примеры команд CLI (чеклист)

Полный пользовательский набор — в [wiki-raid.md](wiki-raid.md). Ниже — компактный чеклист для реализации и тестов.

**Dry-run**

```bash
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --dry-run
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --json
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --dry-run --json
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --no-stash --json
```

**Full commit**

```bash
export RACCPACK_PASSPHRASE='…'
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --json
```

**Phase toggles**

```bash
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-stash
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-rinse
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-pack
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-stash --no-rinse
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-rinse
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --keep-sources
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --min-risk critical
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --min-risk medium
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-content-deny
```

**Paths / config**

```bash
racc raid --project . --den ~/.raccpack/den --yes
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den \
  --config ~/.config/raccpack/config.toml --yes
```

**Passphrase**

```bash
export RACCPACK_PASSPHRASE='…'
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes
RACCPACK_PASSPHRASE='…' racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --no-stash   # no pass needed
```

**JSON / CI / jq**

```bash
RACCPACK_PASSPHRASE="$SECRET" \
  racc raid --project "$CI_PROJECT_DIR" --den "$DEN" --yes --json

racc raid --project "$CI_PROJECT_DIR" --den "$DEN" --yes --json | jq '.success'
racc raid --project "$CI_PROJECT_DIR" --den "$DEN" --yes --json | jq '.stages'
racc raid --project "$CI_PROJECT_DIR" --den "$DEN" --yes --json | jq -r '.den_artifacts[]'
racc raid --project "$CI_PROJECT_DIR" --den "$DEN" --json | jq '{success, dry_run, stages}'
```

**Негативные**

```bash
racc raid --den ~/.raccpack/den --yes
# → exit 1, нет --project

RACCPACK_PASSPHRASE= racc raid --project PATH --den DEN --yes
# → exit 1, пустой/отсутствующий passphrase при включённом stash

racc raid --project PATH --den DEN --dry-run --yes
# → dry-run wins, no write

racc raid --project PATH --den DEN --min-risk ultra --yes
# → exit 1, unknown risk
```

## 6. E2E alpha checklist

Fixture:

```text
fixture/
  app/
    Cargo.toml
    src/main.rs
    .env              # secret
    node_modules/x    # trash
    notes.txt
```

```bash
export RACCPACK_PASSPHRASE='test-only-pass'
DEN=/tmp/racc-den-alpha
rm -rf "$DEN"

# dry-run
cargo run -p raccpack-cli -- raid --project fixture/app --den "$DEN"
test ! -d "$DEN/secrets" || test -z "$(find "$DEN/secrets" -name '*.age' 2>/dev/null)"

# commit
cargo run -p raccpack-cli -- raid --project fixture/app --den "$DEN" --yes

# asserts
test -f "$DEN"/.den-version
find "$DEN/secrets" -name '*.age' | grep -q .
find "$DEN/packs" -name '*.tar.zst' | grep -q .
find "$DEN/manifests" -name '*.json' | grep -q .
test ! -f fixture/app/.env                    # if remove_sources default
test ! -d fixture/app/node_modules            # rinse
# pack has notes.txt, no .env
```

Автотест: `tests/e2e_raid.rs` с assert_cmd + tempfile.
