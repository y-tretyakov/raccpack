## 1. Цель

```bash
racc rinse --project PATH
racc rinse --project PATH --yes
racc rinse --project PATH --dry-run --json
racc rinse --project PATH --strategy rust --strategy node --yes
```

Default: **DryRun**. `--yes` → Commit (удаление).

Полный набор пользовательских примеров — в [wiki-rinse.md](wiki-rinse.md) (секция «Примеры команд CLI»). Ниже — компактный чеклист для реализации и тестов.

### 1.1. Примеры команд (чеклист реализации)

**Dry-run**

```bash
racc rinse --project ~/DEV/PROJS/my-api
racc rinse --project ~/DEV/PROJS/my-api --dry-run
racc rinse --project ~/DEV/PROJS/my-api --json
racc rinse --project ~/DEV/PROJS/my-api --dry-run --json
```

**Commit**

```bash
racc rinse --project ~/DEV/PROJS/my-api --yes
```

**Стратегии**

```bash
racc rinse --project ~/DEV/PROJS/my-api --strategy rust --yes
racc rinse --project ~/DEV/PROJS/my-api --strategy node --yes
racc rinse --project ~/DEV/PROJS/my-api --strategy python --yes
racc rinse --project ~/DEV/PROJS/my-api --strategy jvm --yes
racc rinse --project ~/DEV/PROJS/my-api --strategy go --yes
racc rinse --project ~/DEV/PROJS/my-api --strategy generic --yes
racc rinse --project ~/DEV/PROJS/my-api --strategy rust --strategy node --yes
```

**Config / cwd**

```bash
racc rinse --project . --yes
racc rinse --project ~/DEV/PROJS/my-api --config ~/.config/raccpack/config.toml
```

**CI / jq**

```bash
racc rinse --project "$CI_PROJECT_DIR" --json
racc rinse --project "$CI_PROJECT_DIR" --strategy node --yes --json
racc rinse --project ~/DEV/PROJS/my-api --json | jq '.bytes_freed'
racc rinse --project ~/DEV/PROJS/my-api --json | jq -r '.removed[].path'
```

**Негативные**

```bash
racc rinse --yes                          # → exit 1, нет --project
racc rinse --project PATH --strategy foo  # → exit 1, unknown strategy
racc rinse --project PATH --dry-run --yes # → dry-run wins, no delete
```

## 3. Clap

```text
racc rinse [OPTIONS]

Required:
      --project <PATH>       Project root to clean

Options:
      --yes                  Commit: actually delete trash dirs
      --dry-run              Force dry-run (default)
      --strategy <ID>        Repeatable: rust|node|python|jvm|go|generic
                             If omitted → config cleanup.enabled_strategies
      --json
      --den <PATH>           Ignored for rinse logic (optional global consistency)
```

Нет passphrase. Нет `--remove-sources`.

Mapping:

| CLI | RinseOptions / mode |
|-----|---------------------|
| default | DryRun |
| `--yes` | Commit |
| `--strategy` repeated | strategies: Some([...]) |
| none | strategies: None → config |

## 4. Поток

```text
1. load config + overrides
2. mode from --yes / --dry-run
3. RinseOptions { target: project, strategies, include_custom_patterns: false }
4. rinse(&ctx, &opts, progress)?
5. human or JSON
6. exit 0/1
```

Human DryRun:

```text
Rinse (dry-run)
  Project: /…/my-api
  Would remove 2 directories (140.2 MiB)
    node_modules  [node]  120.0 MiB
    target        [rust]   20.2 MiB
  (nothing deleted)
```

Commit:

```text
Rinse complete
  Removed 2 directories, freed 140.2 MiB
```
