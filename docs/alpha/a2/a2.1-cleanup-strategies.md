# A2.1 — Стратегии cleanup (rust/node/python/…) + config toggles

**Фаза:** A2 — Rinse  
**Зависимости:** M1.4 walk/SkipPolicy, M1.3 config  
**Параллельность:** Dev + Test

---

## 1. Цель

Определить **data-driven стратегии очистки** «мусорных» каталогов сборки/кэша:

- именованные стратегии (`rust`, `node`, `python`, …);
- каждая = набор **точных имён директорий** (и опционально glob на один сегмент);
- обнаружение кандидатов под `target` project root;
- **config toggles**: какие стратегии включены по умолчанию;
- **без** удаления (A2.2) и без CLI.

Инвариант: rinse удаляет только **известные trash-dirs**, не произвольные user files и не secret files по содержимому.

### 3.1. Осторожные имена (`dist`, `build`, `vendor`)

| Имя | Политика MVP |
|-----|----------------|
| `target` | всегда в rust strategy |
| `node_modules` | всегда в node |
| `dist` / `build` | в strategy, но **default enabled strategies** могут исключать `generic` и спорные — зафиксировать defaults: `rust`, `node`, `python` **без** go vendor / generic tmp |
| `vendor` (Go) | strategy go **default off** |

Default enabled в config:

```toml
[cleanup]
enabled_strategies = ["rust", "node", "python"]
```

## 4. Config

```rust
#[derive(Debug, Clone, Deserialize)]
pub struct CleanupConfig {
    /// Strategy ids enabled when RinseOptions.strategies is None
    #[serde(default = "default_enabled_strategies")]
    pub enabled_strategies: Vec<String>,
}

fn default_enabled_strategies() -> Vec<String> {
    vec![
        "rust".into(),
        "node".into(),
        "python".into(),
    ]
}
```

В `RaccConfig`:

```rust
pub struct RaccConfig {
    // …
    #[serde(default)]
    pub cleanup: CleanupConfig,
}
```

Невалидный id в конфиге → ConfigError при validate **или** ignore unknown с warning — **рекомендация: Error на неизвестный id** (strict).

## 5. Detect API

```rust
// clean/detect.rs

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct TrashDir {
    pub path: PathBuf,
    pub strategy: String,      // strategy id as_str
    pub pattern_name: String,  // e.g. "node_modules"
    pub size_bytes: u64,       // dir total; 0 if not computed yet
}

pub struct DetectTrashOptions {
    pub target: PathBuf,
    pub strategy_ids: Vec<StrategyId>,
    pub max_depth: usize,
    /// Compute size_bytes for each hit (walk files). Default true for rinse UX.
    pub compute_size: bool,
}

pub fn find_trash_dirs(opts: &DetectTrashOptions) -> Result<Vec<TrashDir>, Error>;
```

Алгоритм:

```text
1. ensure target is dir
2. collect patterns from selected strategies
3. walk (follow_links false); for each **directory** whose file_name matches a pattern:
     - record TrashDir
     - **do not descend into** that dir further for *other* trash discovery
       (optional: still don't follow inside for size — size walk can be separate restricted walk)
4. if compute_size: sum file sizes under that dir (no symlink follow)
5. sort by path
```

**Не** удалять в A2.1.

Path safety: only under `target` (strip_prefix check).

## 6. Тесты

1. Fixture: `proj/target/debug/x`, `proj/node_modules/a`, `proj/src/main.rs` → finds target + node_modules, not src.
2. Strategy filter: only `rust` → no node_modules.
3. `compute_size`: size ≥ size of known file inside.
4. Symlink to external huge dir → not followed / not counted as external content.
5. `StrategyId::from_str_ignore_case("Node")` works.
6. Default strategies list contains rust/node/python.
7. Unknown strategy string in helper → None/Error.

```bash
cargo test -p raccpack-core clean strategy detect
```
