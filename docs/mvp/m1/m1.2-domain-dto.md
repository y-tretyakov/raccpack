## 1. Цель этапа

Зафиксировать **стабильный минимальный набор domain-типов** в `raccpack-core`, которыми будут пользоваться:

- facade (`sniff`, `dig`, …) на следующих фазах;
- CLI / TUI / Desktop через serde JSON;
- отчёты и exit-policy.

Типы **без** UI-зависимостей, без файлового I/O, без git/age. Только данные и ошибки.

## 4. Типы — детальная спецификация

### 4.1. `SensitiveRisk`

Уровни риска находки секрета. Используются в dig, stash, pack deny, exit policy.

```rust
/// Severity of a sensitive finding.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
#[derive(serde::Serialize, serde::Deserialize)]
#[serde(rename_all = "PascalCase")] // или "snake_case" — зафиксировать одно
pub enum SensitiveRisk {
    /// Informational / low confidence.
    Low,
    /// Worth reviewing.
    Medium,
    /// Likely secret; default min for stash.
    High,
    /// Almost certainly credential / key material.
    Critical,
}
```

Требования:

- `Ord` / `PartialOrd` — Critical > High > Medium > Low (для `min_risk` фильтров).
- Serde: стабильные имена в JSON (не менять без breaking).
- Методы-хелперы (опционально, но полезно):

```rust
impl SensitiveRisk {
    pub fn as_str(self) -> &'static str { /* ... */ }
    pub fn from_str_ignore_case(s: &str) -> Option<Self> { /* ... */ }
}
```

Запрет: не смешивать с HTTP status / CLI exit codes внутри enum.

### 4.2. `Stack`

Описание технологического стека проекта (результат detect).

Минимум для MVP:

```rust
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
#[derive(serde::Serialize, serde::Deserialize)]
pub struct Stack {
    /// Primary language, if detected (e.g. "Rust", "TypeScript").
    pub language: Option<String>,
    /// Framework / runtime hints (e.g. "Axum", "Next.js").
    pub frameworks: Vec<String>,
    /// Raw marker hits that contributed (optional, for debug).
    pub markers: Vec<String>,
}
```

Альтернатива (если хотите строже):

```rust
pub enum Language { Rust, TypeScript, Python, Go, Unknown, /* ... */ }
```

На M1.2 достаточно **строковых** полей: точный enum языков появится в M2.2 (detect). Не блокировать M1.2 полным справочником.

`Default` для «ещё не детектили»:

```rust
impl Default for Stack {
    fn default() -> Self {
        Self {
            language: None,
            frameworks: Vec::new(),
            markers: Vec::new(),
        }
    }
}
```

### 4.3. `Project`

```rust
use std::path::PathBuf;

#[derive(Debug, Clone, PartialEq, Eq)]
#[derive(serde::Serialize, serde::Deserialize)]
pub struct Project {
    /// Absolute or normalized path to project root.
    pub path: PathBuf,
    /// Directory name (or derived display name).
    pub name: String,
    pub stack: Stack,
    /// Total size in bytes (files under project, after skip policy — позже).
    pub size_bytes: u64,
    pub is_git_repo: bool,
    // git_state — позже (Alpha A4); в M1.2 не обязательно
}
```

Инварианты (документировать в rustdoc):

- `name` обычно `path.file_name()`, но может быть override.
- `path` не обязан быть canonicalized на этапе DTO; нормализация — ответственность caller/facade.

### 4.4. `ScanReport`

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
#[derive(serde::Serialize, serde::Deserialize)]
pub struct ScanReport {
    /// Root that was scanned.
    pub root: PathBuf,
    pub projects: Vec<Project>,
    pub total_size_bytes: u64,
    /// Schema version for JSON consumers (CI).
    pub schema_version: u32,
}
```

- `schema_version`: начать с `1`.
- `total_size_bytes` = сумма `project.size_bytes` (или независимый подсчёт — зафиксировать в docs, что сумма projects).

### 4.5. `Error` (библиотечный)

Единый error type core. **Без** `anyhow` в public API.

```rust
use std::path::PathBuf;

#[derive(Debug, thiserror::Error)]
pub enum Error {
    #[error("path not found: {path}")]
    PathNotFound { path: PathBuf },

    #[error("not a directory: {path}")]
    NotADirectory { path: PathBuf },

    #[error("io error at {path}: {source}")]
    Io {
        path: PathBuf,
        #[source]
        source: std::io::Error,
    },

    #[error("invalid configuration: {message}")]
    Config { message: String },

    #[error("{message}")]
    Other { message: String },
    // Добавлять варианты по мере фаз; не раздувать заранее
}

impl Error {
    /// Optional UX hint (CLI/TUI/Desktop).
    pub fn suggestion(&self) -> Option<&'static str> {
        match self {
            Error::PathNotFound { .. } => Some("Check that scan_root exists and is accessible."),
            Error::NotADirectory { .. } => Some("Provide a directory path, not a file."),
            _ => None,
        }
    }
}

pub type Result<T> = std::result::Result<T, Error>;
```

Зависимости:

- `thiserror` — да (workspace.dependency).
- `serde` + `serde_json` — для DTO (Serialize/Deserialize).
- **Не** `anyhow` в signature public Error.
- **Не** `Box<dyn std::error::Error>` в public API.

`Config` variant временный: в M1.3 появится отдельный `ConfigError` или расширится этот enum — решить при M1.3, не ломая M1.2 без нужды.

## 5. Serde-соглашения (зафиксировать)

| Решение | Рекомендация |
|---------|----------------|
| Имена полей | `snake_case` в Rust и в JSON (serde default) |
| Enum variant names | `PascalCase` в JSON **или** `snake_case` — **выбрать одно** и написать в rustdoc |
| PathBuf | serde поддерживает из коробки как строку |
| Option | omit_none не обязателен на M1.2 |

Добавить smoke-тест roundtrip:

```rust
#[test]
fn scan_report_json_roundtrip() {
    let report = ScanReport { /* ... */ };
    let json = serde_json::to_string(&report).unwrap();
    let back: ScanReport = serde_json::from_str(&json).unwrap();
    assert_eq!(report, back);
}
```

## 7. Тесты (Test-субагент)

Обязательные кейсы:

1. `SensitiveRisk` ordering: `Low < Medium < High < Critical`.
2. `SensitiveRisk` serde roundtrip для каждого варианта.
3. `Stack::default()` — пустые frameworks/markers, language None.
4. `Project` + `ScanReport` serde roundtrip (с PathBuf).
5. `Error::suggestion()` возвращает Some для PathNotFound / NotADirectory.
6. `Error` реализует `std::error::Error` + `Display`.
7. Нет `unwrap` в non-test production коде этого этапа (типов почти нет — ок).

Команда узкого набора:

```bash
cargo test -p raccpack-core -- domain
# или
cargo test -p raccpack-core risk report project error
```

## 8. Ограничения и запреты

- Не реализовывать `SensitiveFile`, `RepeatedSecret`, `RaidResult` — они появятся в M3 / A3.
- Не добавлять git-типы (`GitState`) — Alpha A4.
- Не класть в DTO raw secret values.
- Не использовать `anyhow::Error` как public type.
- Не делать breaking-изменения имён полей после того, как CLI начнёт печатать JSON (пока CLI stub — можно ещё править, но стремиться к стабильности).
