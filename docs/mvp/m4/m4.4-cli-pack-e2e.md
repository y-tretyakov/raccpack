## 1. Цель этапа

1. Команда CLI:

```bash

racc pack --project PATH --den PATH --yes   # Commit (explicit)
```

2. **Ручной / автоматизируемый E2E MVP:** sniff → dig → pack на fixture, артефакт в den.

Этим закрывается **MVP 0.1.0** по roadmap exit criteria.

---

## 2. Контекст

Из roadmap M4.4:

> CLI: `racc pack --project … --den …`; ручной E2E MVP.

**MVP exit criteria:**

> на реальной папке проектов CLI показывает sniff/dig и создаёт pack в den без TUI/Desktop/age/rinse.

Default mode: **DryRun** для destructive-ish ops (vision). Pack пишет файлы → Commit только с `--yes` / `--commit` / explicit flag.

Рекомендация CLI:

| Flag | Mode |
|------|------|
| (default) | DryRun — показать что будет сделано |
| `--yes` / `--commit` | RunMode::Commit |
| `--dry-run` | явный DryRun |

---

## 3. Clap

```text
racc pack [OPTIONS]

Options:
      --project <PATH>       Project directory to pack (required)
      --den <PATH>           Den directory (or config / global --den)
      --root <PATH>          Optional; used if resolving relative project
      --json
      --dry-run              Force dry-run
      --yes                  Commit (write archive to den)
      --no-content-deny      Disable content secret deny
      --zstd-level <N>
      --output-name <NAME>   Override artifact file name
```

Если и `--dry-run`, и `--yes` — ошибка clap или приоритет dry-run.

`--project` обязателен.  
`--den` обязателен **или** из config `paths.den_dir`.

---

## 4. Поток `run_pack`

```text
1. Load config + overrides (--den, --root, --config)
2. mode = if yes && !dry_run { Commit } else { DryRun }
3. AppContext
4. PackOptions { project, output_name, deny_content_secrets: !no_content_deny, zstd_level }
5. result = pack(&ctx, &opts, progress)?
6. if json → print PackResult
   else → human:
        Dry-run: "Would write: … (N files, skip secrets: K)"
        Commit: "Wrote: … (size, files, skipped)"
7. exit 0 on success; 1 on error
```

Pack **не** использует exit code 2 (это secrets policy для dig).

## 7. E2E MVP checklist (ручной / script)

Fixture layout:

```text
fixture_root/
  app/
    Cargo.toml
    src/main.rs
    .env                 # secret by name
    notes.txt
```

Команды:

```bash
# 1. sniff
cargo run -p raccpack-cli -- sniff --root fixture_root
cargo run -p raccpack-cli -- sniff --root fixture_root --json

# 2. dig
cargo run -p raccpack-cli -- dig --root fixture_root
cargo run -p raccpack-cli -- dig --root fixture_root --json --fail-on ignore

# 3. pack dry-run
cargo run -p raccpack-cli -- pack --project fixture_root/app --den /tmp/racc-den-test --dry-run

# 4. pack commit
cargo run -p raccpack-cli -- pack --project fixture_root/app --den /tmp/racc-den-test --yes

# 5. verify den
ls /tmp/racc-den-test/packs/*/*/*.tar.zst
test -f /tmp/racc-den-test/.den-version
test -f /tmp/racc-den-test/README.txt
```

Критерий E2E:

- [ ] sniff видит `app` / Rust.
- [ ] dig видит `.env`.
- [ ] pack --yes создаёт `.tar.zst` в den.
- [ ] `.den-version` == `1`.
- [ ] В архиве нет `.env`, есть `notes.txt` / `src/main.rs`.

Опционально: добавить `tests/e2e_mvp.rs` с `assert_cmd` + tempfile (рекомендуется).
