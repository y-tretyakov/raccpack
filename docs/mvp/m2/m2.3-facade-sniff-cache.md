## 1. Цель этапа

Собрать **публичный use-case `sniff`**:

- вход: `AppContext` (или эквивалент paths+config) + `SniffOptions` + `ProgressSink`;
- выход: `SniffResult { report: ScanReport, from_cache, duration_ms }`;
- опциональный **versioned file cache**, чтобы повторный sniff того же root был быстрым.

Это первый facade-метод core. CLI (M2.4) станет тонкой обёрткой.

## 2. Контекст (facade-документ §3)

```rust
pub struct SniffOptions {
    pub force_refresh: bool,
    pub max_depth: Option<usize>,
}

pub struct SniffResult {
    pub report: ScanReport,
    pub from_cache: bool,
    pub duration_ms: u64,
}

pub fn sniff(
    ctx: &AppContext,
    opts: &SniffOptions,
    progress: &mut dyn ProgressSink,
) -> Result<SniffResult>;
```

Поведение:

- Root = `ctx.paths.scan_root` (должен существовать).
- Cache: если `!force_refresh` и cache fresh → `from_cache: true`.
- Progress: phase `"scan"`.
- **Не** читает содержимое на секреты.

## 4. Алгоритм `sniff`

```text
1. t0 = Instant::now()
2. root = ctx.paths.scan_root
3. ensure_scan_root(&root)?
4. max_depth = opts.max_depth.unwrap_or(ctx.config.scanner.max_depth)
5. progress.emit(phase="scan", percent=0, message="starting")
6. if !opts.force_refresh {
       if let Some(report) = cache::try_load(&root, cache_key_inputs)? {
           progress.emit(... complete, from cache)
           return Ok(SniffResult { report, from_cache: true, duration_ms })
       }
   }
7. candidates = find_candidates(root, CandidateOptions { max_depth, policy, .. })?
8. progress.emit(... "detecting stacks")
9. projects = []
   for c in candidates {
       stack = stack_from_candidate(&c) // + optional enrich
       size = project_size_bytes(&c.path, &policy, max_depth).unwrap_or(0)
       projects.push(candidate_to_project(c, stack, size))
       // optional progress percent by index
   }
10. total_size = sum(projects.size_bytes)
11. report = ScanReport {
        root: root.to_path_buf(),
        projects,
        total_size_bytes: total_size,
        schema_version: 1,
    }
12. cache::store(&root, &report, cache_key_inputs)?  // best-effort: ошибка cache не валит sniff
13. progress.emit(phase_complete, percent=100)
14. Ok(SniffResult { report, from_cache: false, duration_ms: elapsed })
```

### Progress

Минимум событий:

| Момент | phase | percent (overall) | message |
|--------|-------|-------------------|---------|
| старт | scan | 0 | Scanning… |
| после candidates | scan | 40 | Found N candidates |
| после stacks/sizes | scan | 90 | Building report |
| конец | scan | 100 | Done | phase_complete=true |

`OperationKind::Sniff`. Без raw paths secrets (их нет).

## 5. Cache (простой versioned)

### 5.1. Где хранить

Варианты:

| Вариант | Путь | Плюсы |
|---------|------|--------|
| A | `{den_dir}/.cache/sniff/{hash}.json` | рядом с den |
| B | `{scan_root}/.raccpack/sniff-cache.json` | рядом с проектами |
| C | XDG cache: `~/.cache/raccpack/sniff/{hash}.json` | не засоряет проекты |

**Рекомендация MVP:** **C (XDG cache)** или рядом с den, если den задан.  
Не писать в `scan_root` по умолчанию (пользователь может не хотеть мусора в DEV).

Зафиксировать одно место в rustdoc.

### 5.2. Ключ и версия

Cache entry JSON:

```json
{
  "cache_schema": 1,
  "core_version": "0.1.0",
  "root": "/abs/path",
  "max_depth": 6,
  "policy_fingerprint": "default_scan_v1",
  "created_at": "2026-08-04T15:00:00Z",
  "report": { /* ScanReport */ }
}
```

Инвалидация, если изменилось любое из:

- `cache_schema`
- `core_version` (или отдельный `SNIFF_CACHE_VERSION` const)
- `max_depth`
- `policy_fingerprint` (строка/хэш от default policy id)
- abs path root

**Свежесть по mtime дерева:** для MVP **не** обязательно ходить по всему дереву сверяя mtime (дорого). Простой cache = «пока force_refresh или version mismatch — пересчёт».  
Опционально later: store root mtime / hash.

`force_refresh: true` → всегда пересчёт + overwrite cache.

### 5.3. API cache

```rust
pub fn try_load_sniff_cache(
    root: &Path,
    max_depth: usize,
    policy_fp: &str,
) -> Result<Option<ScanReport>, Error>;

pub fn store_sniff_cache(
    root: &Path,
    max_depth: usize,
    policy_fp: &str,
    report: &ScanReport,
) -> Result<(), Error>;
```

Ошибки записи cache: **глотать** на уровне sniff (log via `tracing` если есть, иначе ignore) — sniff успешен без cache.  
Ошибки чтения: treat as miss.

## 8. Тесты (обязательные)

1. **Empty root** → report с 0 projects, success.
2. **Fixture с 2 проектами** → `projects.len() == 2`, names/paths ожидаемые, total_size > 0.
3. **Skip policy** → нет project из `node_modules`.
4. **Cache hit:** первый sniff `from_cache=false`, второй без force → `from_cache=true`, report равен.
5. **force_refresh** → `from_cache=false` даже при существующем cache.
6. **max_depth change** → cache miss.
7. **Progress:** с test sink собираются события; последнее `phase_complete`.
8. **Bad root** → `PathNotFound` / `NotADirectory`.
9. Serde roundtrip `ScanReport` внутри cache file.

Команда:

```bash
cargo test -p raccpack-core sniff cache
```

## 9. Ограничения и запреты

- sniff **не** делает dig/secrets.
- sniff **не** пишет в den/packs.
- Cache miss/error не должен ломать успешный scan.
- Не follow symlinks.
- Не возвращать raw secrets (их нет).
- Public signature `sniff` — как в facade-доке (стабилизировать).
