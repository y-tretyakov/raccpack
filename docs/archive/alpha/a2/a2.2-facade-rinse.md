# A2.2 — Facade `rinse` DryRun/Commit + bytes freed

**Фаза:** A2 — Rinse  
**Зависимости:** A2.1, M2.3 AppContext/RunMode/ProgressSink  
**Параллельность:** Dev + Test

---

## 1. Цель

Публичный **`rinse`**:

- DryRun: список `TrashDir` + `bytes_freed`, **без** удаления;
- Commit: удалить найденные dirs, вернуть фактические stats;
- progress;
- **не** трогать secret files отдельно (rinse только dirs из стратегий).

```rust
pub fn rinse(
```

```rust
// clean/remove.rs

/// Remove directory tree at path. Returns bytes that were under it (best-effort
/// from prior size_bytes, or recompute before delete).
pub fn remove_trash_dir(path: &Path) -> Result<u64, Error>;
```

Реализация: `std::fs::remove_dir_all` после проверки path containment under target.  
Не follow symlink mounts наружу — если `path` сам symlink на dir, **не удалять** (skip + warn) или удалить только symlink — **MVP: skip symlink dirs** (safety).

## 4. Алгоритм `rinse`

```text
1. progress 0% "scanning trash"
2. resolve strategy ids:
     opts.strategies if Some
     else ctx.config.cleanup.enabled_strategies
     parse → Vec<StrategyId>; unknown → Error
3. find_trash_dirs(DetectTrashOptions {
     target: opts.target,
     strategy_ids,
     max_depth: ctx.config.scanner.max_depth or 64,
     compute_size: true,
   })
4. bytes = sum size_bytes
5. if DryRun:
     progress 100%
     return RinseResult { removed: dirs, bytes_freed: bytes, dry_run: true }
6. progress "removing"
7. for dir in dirs:
     verify dir.path starts with target
     if symlink → skip (or Error — prefer skip + count not removed)
     remove_dir_all
     accumulate freed
8. progress 100%
9. return RinseResult { removed: successfully_removed, bytes_freed: freed, dry_run: false }
```

**Partial failure:** fail-fast on first remove error (MVP); already removed stay removed (document).  
Альтернатива later: continue_on_error.

`include_custom_patterns`: если в config нет custom — no-op. Не блокировать A2.2.

## 6. Тесты

1. DryRun: dirs listed, filesystem unchanged (node_modules still exists).
2. Commit: node_modules/target removed; bytes_freed > 0.
3. Strategies filter from options overrides config.
4. Unknown strategy string → Error.
5. Path outside target not deleted even if passed somehow.
6. Empty project → removed empty, bytes 0, Ok.
7. Symlink dir to /tmp/evil → not remove_dir_all on external (skip).
