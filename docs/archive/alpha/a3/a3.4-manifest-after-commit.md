# A3.4 — Manifest JSON только после successful commit

**Зависимости:** A3.3 Atomic (manifest не пишем при rollback)  
**Бывший** пункт backlog WORKLOG «A3.3 manifest» — перенесён сюда.

---

## 1. Цель

После **успешного** Atomic commit:

```text
{den}/manifests/{yyyy}/{mm}/{slug}__{ts}__{short_id}.json
```

- Не писать при `success: false` / `rolled_back`  
- Не писать в DryRun  
- Paths relative to den; no raw secrets  
- schema_version: 1  

Поля: stages, artifacts (secrets_archive, project_pack), stash_manifest entries, tool version, success, dry_run, created_at.

Опционально в JSON CLI `RaidResult` уже есть stages — manifest на диске для audit.

---

## 2. Модульность

```text
den/manifest.rs
app/raid/mod.rs   # call write only on Atomic success path after renames
```

---

## 3. Тесты

- Success Commit → file exists, parses.  
- Forced failure / rollback → no manifests entry for that raid_id.  
- DryRun → none.
