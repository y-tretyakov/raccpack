# A4.3 — Логи tracing без секретов; `--verbose`

**Фаза:** A4 — Git и DX alpha  
**Зависимости:** CLI main, all commands  
**Параллельность:** Dev + Test

---

## 1. Цель

1. Подключить **`tracing`** (+ `tracing-subscriber`) в CLI.
2. Глобальный **`-v` / `--verbose`** (repeatable: `-vv`).
3. Инвариант: **raw secrets never** in log events (passphrase, file content matches, env values).

---

## 2. Модульность и файлы


## 3. Verbosity levels

| Flags | Env equivalent | Level |
|-------|----------------|-------|
| (none) | `RUST_LOG` unset | warn (or error) |
| `-v` | `racc=info` | info |
| `-vv` | `racc=debug` | debug |
| `-vvv` | `racc=trace` | trace |

Also honor `RUST_LOG` if set (override or merge — **рекомендация: RUST_LOG wins if set**).

```rust
pub fn init_tracing(verbose: u8) {
    let filter = std::env::var("RUST_LOG").unwrap_or_else(|_| match verbose {
        0 => "warn".into(),
        1 => "info,raccpack_core=info,raccpack_cli=info".into(),
        2 => "debug,raccpack_core=debug,raccpack_cli=debug".into(),
        _ => "trace,raccpack_core=trace,raccpack_cli=trace".into(),
    });
    tracing_subscriber::fmt()
        .with_env_filter(filter)
        .with_target(true)
        .init();
}
```

## 4. Правила redaction

| Запрещено в logs | Разрешено |
|------------------|-----------|
| passphrase / AgeIdentity | «encrypting N files» |
| raw content match text | masked preview already in DTO only — don't log even masked at info |
| full .env body | path to file, risk level |
| RACCPACK_PASSPHRASE value | «passphrase source: env» |

Code review checklist in PR for A4.3: grep `tracing::` near secrets/age.

## 5. Примеры команд CLI

```bash
# Обычный режим — почти тихо
racc sniff --root ~/DEV/PROJS

# Info: фазы, пути root/den, счётчики
racc sniff --root ~/DEV/PROJS -v
racc dig --project ~/DEV/PROJS/my-api -v
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den -v

# Debug
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes -vv

# Trace (очень шумно)
racc dig --project ~/DEV/PROJS/my-api -vvv

# Через RUST_LOG
RUST_LOG=raccpack_core=debug racc pack --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes

# JSON + verbose: JSON в stdout, логи в stderr
racc dig --project ~/DEV/PROJS/my-api --json -v 2>dig.log

# Проверка: в логах нет passphrase
RACCPACK_PASSPHRASE='secret-test-value' \
  racc stash --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes -vv 2>&1 \
  | tee /tmp/stash.log
grep -i 'secret-test-value' /tmp/stash.log && echo FAIL || echo OK
```

**Комбинации с другими флагами:**

```bash
racc rinse --project ~/DEV/PROJS/my-api --yes -v
racc pack --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes -vv
racc init --scan-root ~/DEV/PROJS -v
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes --json -v
```
