## 3. CI workflow (минимум)

```yaml
name: ci
on:
  push:
  pull_request:
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - name: test
        run: cargo test --workspace
      - name: fmt
        run: cargo fmt --check
      - name: clippy
        run: cargo clippy --workspace -- -D warnings
```

Git binary available on ubuntu-latest for A4.1 process tests.

## 4. Integration coverage matrix

| Test | Assert |
|------|--------|
| sniff | finds marker projects, skip node_modules |
| dig | finds .env, JSON no raw password string |
| stash | age file in den, dry-run no file |
| rinse | dry-run keeps node_modules; --yes removes |
| pack | tar.zst no .env inside |
| raid | age+pack+manifest; success true |
| init | writes config_version |
| git | optional status on dig |

## 5. Примеры команд CLI (локальный прогон как CI)

```bash
# Как в CI
cargo test --workspace
cargo fmt --check
cargo clippy --workspace -- -D warnings

# Только core integration
cargo test -p raccpack-core --test integration_raid
cargo test -p raccpack-core --test integration_dig

# CLI smoke
cargo test -p raccpack-cli

# Ручной alpha smoke (после build)
cargo build -p raccpack-cli
export RACCPACK_PASSPHRASE='ci-test-only'
DEN=/tmp/racc-alpha-den
PROJ=/tmp/racc-alpha-proj
rm -rf "$DEN" "$PROJ"
mkdir -p "$PROJ/src"
echo 'fn main(){}' > "$PROJ/src/main.rs"
echo 'name=x' > "$PROJ/Cargo.toml"
echo 'SECRET=demo' > "$PROJ/.env"
mkdir -p "$PROJ/node_modules/x"

cargo run -p raccpack-cli -- init --scan-root "$PROJ" --den "$DEN" --force --ensure-den
cargo run -p raccpack-cli -- sniff --root "$PROJ" -v
cargo run -p raccpack-cli -- dig --project "$PROJ" --json | jq '.files | length'
cargo run -p raccpack-cli -- raid --project "$PROJ" --den "$DEN" --yes -v
find "$DEN" -type f
```

**Проверка redaction:**

```bash
RACCPACK_PASSPHRASE='unique-pass-xyz' \
  cargo run -p raccpack-cli -- stash --project "$PROJ" --den "$DEN" --yes -vv 2>&1 \
  | grep -F 'unique-pass-xyz' && echo 'LEAK' || echo 'OK'
```
