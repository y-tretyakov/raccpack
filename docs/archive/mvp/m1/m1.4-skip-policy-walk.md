## 1. Цель этапа

Дать `raccpack-core` **единый, безопасный примитив обхода дерева**:

1. **SkipPolicy** — правила «какие директории/файлы не заходить / не рассматривать».
2. **Walk-хелпер** — обёртка над обходом FS с обязательным `follow_links(false)` и уважением policy + max_depth.

Это фундамент для M2 (sniff / markers) и M3 (dig). Без правильного walk легко получить symlink-cycles, уход за пределы root и сканирование `node_modules` целиком.

## 4. SkipPolicy — спецификация

### 4.1. Что пропускаем по умолчанию (MVP)

Типичный набор directory names (case-sensitive на Linux; зафиксировать поведение на macOS/Windows later):

```text
node_modules
target          # Rust
.git            # обычно не сканируем содержимое как «проект внутри», но is_git_repo детектим отдельно
.svn
.hg
__pycache__
.venv
venv
.tox
.mypy_cache
.pytest_cache
.cache
dist
build
.idea
.vscode
.DS_Store       # файл, не dir — см. ниже
*.egg-info
.raccpack       # свой мета-каталог, если появится
```

Разделить:

- **directory skip** — не входить внутрь;
- **file skip** — не отдавать в iterator (опционально на M1.4);
- **hard-deny names** для pack (может пересекаться; полный name-deny secrets — M3/M4).

На M1.4 достаточно **directory-centric** policy.

### 4.2. API

```rust
use std::path::Path;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SkipReason {
    DefaultDirName,
    CustomPattern,
    Hidden,           // optional: skip dot-dirs except whitelist
    MaxDepth,
    // …
}

#[derive(Debug, Clone)]
pub struct SkipPolicy {
    /// Directory names that are never entered (exact match on file_name).
    dir_names: Vec<String>, // or HashSet
    /// Extra caller patterns (optional).
    custom_dir_names: Vec<String>,
    skip_hidden_dirs: bool,
}

impl SkipPolicy {
    /// Built-in defaults suitable for source-tree scanning.
    pub fn default_scan() -> Self { /* ... */ }

    /// Empty policy (only max_depth / explicit filters apply).
    pub fn empty() -> Self { /* ... */ }

    pub fn with_custom_dir_names(mut self, names: impl IntoIterator<Item = impl Into<String>>) -> Self;

    /// Returns true if this directory should not be descended into.
    pub fn should_skip_dir(&self, path: &Path) -> bool {
        self.skip_reason_dir(path).is_some()
    }

    pub fn skip_reason_dir(&self, path: &Path) -> Option<SkipReason>;
}
```

Реализация `should_skip_dir`:

1. Взять `path.file_name()` → lossy string.
2. Проверить точное совпадение с `dir_names` / `custom_dir_names`.
3. Если `skip_hidden_dirs` и имя начинается с `.` и не в whitelist (`.github`? — решить: для MVP проще skip all dot-dirs **кроме** явно разрешённых, или наоборот не skip hidden и положиться только на список).

**Рекомендация MVP:** не включать агрессивный «skip all hidden»; только явный список + опциональный флаг.

### 4.3. Расширяемость

Позже config сможет подмешивать `custom_skip_dirs`. На M1.4 — programmatic only.

## 5. Walk-хелпер

### 5.1. Зависимость

```toml
[dependencies]
walkdir = "2"
```

**Обязательно** при создании:

```rust
WalkDir::new(root)
    .follow_links(false)   // INVARIANT
    .max_depth(max_depth)  // from options / config
    // .same_file_system(true) — опционально, полезно; решить
```

### 5.2. Options

```rust
#[derive(Debug, Clone)]
pub struct WalkOptions {
    pub max_depth: usize,
    pub policy: SkipPolicy,
    /// If true, yield the root itself as first entry.
    pub include_root: bool,
}

impl Default for WalkOptions {
    fn default() -> Self {
        Self {
            max_depth: 6, // sync with ScannerConfig default
            policy: SkipPolicy::default_scan(),
            include_root: false,
        }
    }
}
```

### 5.3. Публичный iterator / callback API

Вариант A — iterator of `walkdir::DirEntry` (простой):

```rust
/// Walk `root`, skipping dirs per policy. Never follows symlinks.
pub fn walk_tree(
    root: &Path,
    opts: &WalkOptions,
) -> impl Iterator<Item = Result<walkdir::DirEntry, walkdir::Error>> {
    // filter_map / filter: if entry is dir and should_skip → WalkDir::new(...).filter_entry(...)
}
```

Правильный способ со `walkdir` — **`filter_entry`**:

```rust
WalkDir::new(root)
    .follow_links(false)
    .max_depth(opts.max_depth)
    .into_iter()
    .filter_entry(|e| {
        if e.file_type().is_dir() {
            !opts.policy.should_skip_dir(e.path())
        } else {
            true
        }
    })
```

Вариант B — свой enum событий (ближе к будущему WalkSession из workflow 7.x):

```rust
pub enum WalkEvent {
    EnterDir { path: PathBuf },
    File { path: PathBuf },
    SkipDir { path: PathBuf, reason: SkipReason },
    // …
}
```

На **M1.4** достаточно варианта A (iterator + filter_entry). WalkEvent — design later (7.1).

### 5.4. Path containment (минимум)

Дополнительная защита (рекомендуется):

```rust
/// True if `child` is under `root` (after both are absolute/normalized as far as possible).
pub fn is_under_root(root: &Path, child: &Path) -> bool;
```

Использовать при выдаче entries, если path «уехал» (редко без symlinks, но дешёвая проверка). Без `canonicalize` всего дерева — через `strip_prefix` после `dunce`/`absolute`.

На M1.4 можно отложить полную containment, но **задокументировать** как follow-up перед pack/stash.

### 5.5. Ошибки обхода

- Permission denied на поддереве → `Error::Io` или пропуск с логом (для MVP: **propagate** в iterator Item=Result, caller решает).
- Root не существует / не dir → сразу `Error::PathNotFound` / `NotADirectory` **до** WalkDir.

```rust
pub fn ensure_scan_root(root: &Path) -> Result<(), Error> {
    if !root.exists() {
        return Err(Error::PathNotFound { path: root.to_path_buf() });
    }
    if !root.is_dir() {
        return Err(Error::NotADirectory { path: root.to_path_buf() });
    }
    Ok(())
}
```

## 7. Тесты (обязательные)

Использовать `tempfile::TempDir`.

1. **follow_links(false):** создать symlink на dir **вне** temp root; walk не должен заходить наружу и не должен падать cycle.
2. **Skip node_modules:** структура  
   `root/a/node_modules/secret.txt` + `root/a/src/main.rs` → iterator видит `main.rs`, не видит содержимое `node_modules`.
3. **Skip target:** аналогично.
4. **max_depth:** файлы глубже N не появляются.
5. **Root validation:** несуществующий path → `PathNotFound`; файл вместо dir → `NotADirectory`.
6. **Default policy** содержит `node_modules` и `target`.
7. **Custom names:** `with_custom_dir_names(["vendor"])` пропускает `vendor`.
8. **Пустое дерево** — не паника, 0 entries (или только root при include_root).
9. **Не следует** symlink-файлу как dir (file symlink — walkdir и так отдаёт как symlink entry; главное — не follow).

Команда:

```bash
cargo test -p raccpack-core skip walk
```

Тесты **не** требуют реального git и сети.

## 8. Ограничения и запреты

- **Запрещено** в production-коде core: `WalkDir::new(...).follow_links(true)` или default без явного `false`.
- Не реализовывать detect markers / Project assembly — это M2.
- Не сканировать content файлов — M3.
- Не удалять и не модифицировать FS — только чтение metadata / listing.
- Не использовать `std::fs::symlink_metadata` vs `metadata` путаницу без тестов.
- Parallel walk (rayon) — не в M1.4 (B4.2 / 5.1).
