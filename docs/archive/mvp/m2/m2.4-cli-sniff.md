**Фаза:** M2 — Sniff (обнаружение проектов)  
**Веха:** MVP → 0.1.0  
**Статус этапа:** todo

**Параллельность:** Dev + Test одновременно

---

## 1. Цель этапа

Сделать **первую полезную CLI-команду**:

```bash
racc sniff --root PATH
racc sniff --root PATH --json
racc sniff --root PATH --force-refresh
```

Тонкая обёртка над `raccpack_core::sniff`: парсинг args → `AppContext` → вызов facade → human или JSON output → exit code.

Без TUI, без dig/raid, без интерактива.

## 4. Clap-интерфейс

### 4.1. Глобальные / корневые флаги

```text
racc [OPTIONS] <COMMAND>

Options:
  -c, --config <PATH>    Config file (overrides RACCPACK_CONFIG)
      --root <PATH>      Override scan_root (also per-command)
      --den <PATH>       Override den_dir (не обязателен для sniff)
      --json             JSON output
  -v, --verbose          Verbose logs (если tracing подключим)
  -h, --help
  -V, --version
```

### 4.2. Команда sniff

```text
racc sniff [OPTIONS]

Options:
      --root <PATH>           Scan root (required if not in config)
      --force-refresh         Ignore sniff cache
      --max-depth <N>         Override max_depth
      --json                  JSON (можно наследовать с глобального)
```

`--root` обязателен **либо** через flag, **либо** через config `paths.scan_root`. Если оба отсутствуют → понятная ошибка с suggestion.

### 4.3. Пример clap-скелета

```rust
use clap::{Parser, Subcommand};

#[derive(Parser)]
#[command(name = "racc", version, about = "Scan projects, find secrets, pack into den")]
struct Cli {
    #[command(subcommand)]
    command: Commands,

    #[arg(long, global = true)]
    config: Option<PathBuf>,

    #[arg(long, global = true)]
    root: Option<PathBuf>,

    #[arg(long, global = true)]
    den: Option<PathBuf>,

    #[arg(long, global = true)]
    json: bool,
}

#[derive(Subcommand)]
enum Commands {
    /// Discover projects under scan root
    Sniff {
        #[arg(long)]
        force_refresh: bool,
        #[arg(long)]
        max_depth: Option<usize>,
    },
}
```

Binary name: **`racc`** (уже в M1.1).

## 5. Поток выполнения `run_sniff`

```text
1. Load config:
   - if cli.config → RaccConfig::load_from_path
   - else RaccConfig::load()
2. Apply overrides:
   - if cli.root → with_scan_root
   - if cli.den → with_den_dir
3. Build AppContext::from_config(config, RunMode::DryRun) // sniff read-only
4. SniffOptions { force_refresh, max_depth }
5. progress = if json { NullProgress } else { CliSpinner or NullProgress }
6. result = sniff(&ctx, &opts, &mut progress)?
7. if json:
       print serde_json::to_string_pretty(&result)?  // or &result.report — зафиксировать
   else:
       print_human_report(&result)
8. exit 0
```

### Что сериализовать в `--json`

**Рекомендация:** весь `SniffResult` (включая `from_cache`, `duration_ms`), чтобы CI видел cache hit. Альтернатива — только `ScanReport`. Зафиксировать в help и тестах.

```json
{
  "report": {
    "root": "/…",
    "projects": [ … ],
    "total_size_bytes": 12345,
    "schema_version": 1
  },
  "from_cache": false,
  "duration_ms": 42
}
```

### Human output (пример)

```text
Scan root: /home/user/DEV/PROJS
Projects: 3  |  Total size: 128.4 MiB  |  42 ms  |  cache: miss

NAME            STACK          SIZE      GIT   PATH
app-api         Rust           12.1 MiB  yes   /home/user/DEV/PROJS/app-api
web             TypeScript     90.0 MiB  yes   /home/user/DEV/PROJS/web
scripts         Python         0.2 MiB   no    /home/user/DEV/PROJS/scripts
```

Требования:

- стабильные колонки;
- size humanized (KiB/MiB);
- stack: language + frameworks коротко;
- без ANSI-обязательности (можно plain); цвета — опционально later.

## 6. Exit codes

| Код | Когда |
|-----|--------|
| 0 | Успех (в т.ч. 0 projects) |
| 1 | Ошибка config / IO / sniff |
| 2 | Зарезервирован под secrets policy (не использовать в sniff) |

Маппинг: `Error` / `ConfigError` → eprintln message + `suggestion()` если есть → exit 1.

## 8. Тесты

### 8.1. Unit / integration в cli crate

- clap parse: `sniff --root /tmp --json` → структура верная.
- Лучше **integration** через `assert_cmd` + `tempfile` fixture с 1–2 marker projects:

```bash
cargo test -p raccpack-cli
```

Кейсы:

1. `racc sniff --root FIXTURE` exit 0, stdout содержит имя проекта.
2. `racc sniff --root FIXTURE --json` — валидный JSON, `projects` length ≥ 1.
3. `racc sniff --root /no/such` exit 1, stderr не пустой.
4. Без `--root` и без config scan_root → exit 1, понятное сообщение.
5. `--force-refresh` принимается (smoke).

### 8.2. Ручной E2E (в отчёте)

```bash
cargo run -p raccpack-cli -- sniff --root /path/to/real/or/fixture
cargo run -p raccpack-cli -- sniff --root … --json | jq .
```

## 9. Ограничения и запреты

- CLI **не** реализует detect/markers сам — только facade.
- Не добавлять subcommands dig/pack «заодно» без этапов M3/M4.
- Не печатать секреты (их нет в sniff).
- Не требовать `--den` для sniff.
- Не делать interactive prompts.
