## 1. Цель этапа

Добавить **сканирование содержимого файлов** на секреты:

- content markers: prefix / regex / simple string rules;
- лимиты размера файла (не читать гигантские бинарники);
- маскирование / fingerprint найденных values (**без raw в public DTO**);
- объединение с filename findings (upgrade risk).

Без facade `dig` целиком (M3.3) и без CLI. Без entropy-heuristics как обязательной части MVP (можно stub).

## 4. Content markers

### 4.1. Структура

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ContentMatchKind {
    /// Line/value starts with prefix (e.g. "AKIA")
    Prefix,
    /// Contains literal needle
    Contains,
    /// Regex (compiled once at startup / lazy)
    Regex,
}

#[derive(Debug, Clone)]
pub struct ContentMarker {
    pub id: &'static str,
    pub kind: ContentMatchKind,
    pub pattern: &'static str,
    pub risk: SensitiveRisk,
    pub label: &'static str,
    /// If true, only apply to text-ish files (by extension / null-byte sniff)
    pub text_only: bool,
}
```

Regex: зависимость `regex` crate. Компилировать в `OnceLock<Regex>` / static `Lazy`.

### 4.2. Default markers (MVP minimum)

| id | kind | pattern | risk | notes |
|----|------|---------|------|-------|
| `aws_access_key` | Prefix | `AKIA` | Critical | AWS access key id |
| `aws_secret_assign` | Regex | `(?i)aws_secret_access_key\s*=\s*\S+` | Critical | |
| `generic_api_key_assign` | Regex | `(?i)(api[_-]?key|apikey)\s*[:=]\s*['\"]?[A-Za-z0-9_\-]{16,}` | High | |
| `generic_secret_assign` | Regex | `(?i)(secret|password|passwd|token)\s*[:=]\s*['\"]?\S{8,}` | High | noisy — tune |
| `private_key_header` | Contains | `-----BEGIN` + `PRIVATE KEY` | Critical | PEM header |
| `github_pat` | Prefix | `ghp_` | Critical | |
| `github_oauth` | Prefix | `gho_` | Critical | |
| `slack_token` | Prefix | `xoxb-` | High | |
| `stripe_live` | Prefix | `sk_live_` | Critical | |
| `stripe_test` | Prefix | `sk_test_` | Medium | |
| `telegram_bot` | Prefix | `bot` + long digit (regex) | High | careful |
| `connection_string` | Regex | `(?i)(postgres\|mysql\|mongodb)://\S+:\S+@` | Critical | |
| `jwt_like` | Regex | `eyJ[A-Za-z0-9_-]+\.eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+` | Medium | |

Начать с **небольшого** надёжного набора (AWS key, PEM header, ghp_, sk_live_, connection string). Расширять табличными тестами, не «на глаз».

### 4.3. File size limits

```rust
pub struct ContentScanLimits {
    /// Skip files larger than this (default 1 MiB or 512 KiB).
    pub max_file_bytes: u64,
    /// Max bytes to read from a file even if smaller limit for regex (default = max_file_bytes).
    pub max_read_bytes: u64,
    /// Skip likely binary (null byte in first 8 KiB).
    pub skip_binary: bool,
}

impl Default for ContentScanLimits {
    fn default() -> Self {
        Self {
            max_file_bytes: 1_048_576, // 1 MiB
            max_read_bytes: 1_048_576,
            skip_binary: true,
        }
    }
}
```

Поведение:

- size > max → skip content scan (filename findings всё ещё возможны);
- binary sniff → skip;
- read error → skip file or Error (MVP: skip content for that file, continue).

### 4.4. Text extensions allow-list (optional aid)

`.env`, `.toml`, `.json`, `.yaml`, `.yml`, `.ini`, `.cfg`, `.conf`, `.properties`, `.py`, `.ts`, `.js`, `.go`, `.rs`, `.env.*`, no extension (often `.env` style) — не обязательный filter, если есть binary sniff.

## 5. Masking & fingerprint

```rust
/// Public-safe preview of a secret value.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct MaskedValue {
    /// e.g. "AKIA…XYZ" or "****"
    pub masked: String,
    /// Stable hash for repeated-secret detection (not raw).
    pub value_hash: String,
    /// Length of original value in bytes/chars (document which).
    pub original_len: usize,
}

/// Mask a secret for reports.
/// - short values (≤ 8): all `*`
/// - longer: keep small prefix (≤ 4) + `…` + small suffix (≤ 2) OR only prefix for keys like AKIA
pub fn mask_secret(raw: &str) -> MaskedValue;

/// Hash for equality of repeated secrets (SHA-256 hex of raw, or blake3).
pub fn fingerprint_secret(raw: &str) -> String;
```

Правила маскирования (зафиксировать + тесты):

| raw len | masked example |
|---------|----------------|
| 0..=4 | `****` |
| 5..=8 | `****` or first1 + `***` |
| > 8 | first 4 + `…` + last 2 (если не key-prefix rule) |
| AWS AKIA… | `AKIA…` + last 4 only if len allows; never full |

**Никогда** не логировать raw. `mask_secret` / fingerprint только в core.

Зависимость: `sha2` или `blake3` для hash.

## 7. Combined scan API

```rust
pub struct SecretScanOptions {
    pub max_depth: usize,
    pub policy: SkipPolicy,
    pub min_risk: SensitiveRisk,
    pub scan_content: bool,          // default true
    pub limits: ContentScanLimits,
    pub find_repeated: bool,         // default false on this stage; full in M3.3
}

pub fn scan_secrets(
    root: &Path,
    opts: &SecretScanOptions,
) -> Result<Vec<SensitiveFinding>, Error>;
```

Алгоритм (один walk):

1. Walk files.
2. Filename match → base finding.
3. If `scan_content` и file eligible → read limited bytes → content markers → hits.
4. Merge by path: upgrade risk, collect sources (или один finding с primary source + list).
5. Sort deterministic.

Repeated secrets across files — можно заготовить map `value_hash → paths` здесь или в M3.3. Минимум M3.2: per-file content hits с mask/hash.

## 8. Тесты (обязательные)

1. File with `AKIA` + random → Critical content hit, masked starts with `AKIA` or `****`, **raw not in Debug of public types** (test MaskedValue).
2. PEM `-----BEGIN RSA PRIVATE KEY-----` → Critical.
3. File > max_file_bytes → no content hit (filename still works if `.env`).
4. Binary file with nulls → skipped for content.
5. Filename `.env` + content password assign → risk = max.
6. `mask_secret("supersecretvalue")` не содержит full string as contiguous raw in `masked` beyond policy.
7. Same raw in two files → same `value_hash`.
8. SkipPolicy: no scan inside `node_modules`.
9. Regex invalid at init — fail compile at test/startup (markers must be valid).
10. Empty file → no panic.

Команда:

```bash
cargo test -p raccpack-core content mask secrets
```

## 9. Ограничения и запреты

- **Raw secret не** в `Serialize` public structs, не в `Display` findings, не в tracing default.
- Не сканировать без size limit.
- Не follow symlinks.
- Не писать на диск.
- Entropy heuristics — не обязательны (stub `use_heuristics` later).
- Не тянуть ML/heavy NLP.
