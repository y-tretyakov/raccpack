## 1. Цель этапа

Реализовать **минимальный den layout** и запись pack-артефакта в него:

- структура каталогов den (v1);
- `.den-version`, `README.txt`;
- именование `packs/{yyyy}/{mm}/{slug}__{timestamp}.tar.zst`;
- staging + atomic rename;
- **без** secrets/ и manifests/ fully (заготовки dirs допустимы);
- **без** полного facade `pack` (M4.3) — низкоуровневый `DenWriter` / `place_pack`.

---

## 2. Контекст (facade-and-den §9)

```text
{den_dir}/
├── README.txt
├── .den-version          # "1"
├── manifests/yyyy/mm/    # later
├── secrets/yyyy/mm/      # later (Alpha)
├── packs/yyyy/mm/
│   └── {slug}__{ts}.tar.zst
├── staging/{short_id}/
└── logs/                 # optional
```

Соглашения имён:

| Токен | Правило |
|-------|---------|
| `project_slug` | sanitize: `[a-zA-Z0-9._-]`, spaces→`-`, len≤80 |
| `utc_timestamp` | `YYYYMMDDThhmmssZ` |
| `short_id` | 8 hex |

Права: den `0700`, `.age` later `0600`; pack files `0600` желательно.

## 4. API

### 4.1. Ensure den

```rust
pub const DEN_VERSION: &str = "1";

pub struct DenPaths {
    pub root: PathBuf,
    pub packs: PathBuf,
    pub staging: PathBuf,
    pub manifests: PathBuf,
    pub secrets: PathBuf,
}

/// Create den skeleton if missing. Idempotent.
/// Writes .den-version and README.txt if absent.
pub fn ensure_den(den_root: &Path) -> Result<DenPaths, Error>;
```

Поведение:

1. `create_dir_all(den_root)`.
2. Unix: `chmod 0o700` best-effort (ignore error on non-Unix).
3. Если нет `.den-version` → write `"1\n"`.
4. Если `.den-version` есть и major несовместим → `Error` (migrate later).
5. Если нет `README.txt` → write template from facade-doc §9.6.
6. `create_dir_all` for `packs`, `staging`, `manifests`, `secrets` (empty ok).

README template:

```text
This directory is a raccpack den (output vault).
- secrets/  encrypted secret batches (age)
- packs/    project archives (no secrets)
- manifests/ JSON metadata for each raid

Do not commit this tree to git.
Keep passphrase offline.
```

### 4.3. Place pack

```rust
pub struct PlacePackRequest {
    pub den_root: PathBuf,
    pub project_name: String,     // for slug
    pub source_archive: PathBuf,  // completed tempfile from pack_tree
    /// If None, generate ts + short_id now
    pub timestamp: Option<String>,
}

pub struct PlacePackResult {
    /// Absolute path to final artifact
    pub absolute_path: PathBuf,
    /// Relative to den_root (for manifests later)
    pub relative_path: PathBuf,
    pub size_bytes: u64,
}

/// Move/rename source_archive into den packs layout atomically.
pub fn place_pack(req: &PlacePackRequest) -> Result<PlacePackResult, Error>;
```

Алгоритм:

```text
1. ensure_den(&req.den_root)?
2. slug = project_slug(&req.project_name)
3. ts = req.timestamp.unwrap_or_else(utc_timestamp_now)
4. rel = packs/yyyy/mm/{slug}__{ts}.tar.zst
5. abs = den_root.join(&rel)
6. create_dir_all(abs.parent())
7. rename source_archive → abs  (same filesystem preferred)
   if cross-device: copy + remove source
8. chmod 0o600 best-effort
9. return paths + size
```

**Не** оставлять orphan в staging при успехе.  
При ошибке rename — source tempfile остаётся у caller.

### 4.4. Staging helper (optional but useful)

```rust
/// staging/{short_id}/pack.tar.zst path for in-progress writes
pub fn staging_pack_path(den_root: &Path, short_id: &str) -> PathBuf;
```

Facade может: pack_tree → staging path → place_pack (rename out of staging).

## 5. Тесты (обязательные)

1. `ensure_den` creates version + readme + dirs; second call idempotent.
2. Wrong `.den-version` (e.g. `99`) → error.
3. `project_slug("My App!")` → sanitized.
4. `place_pack` moves tempfile into `packs/YYYY/MM/slug__ts.tar.zst`.
5. Relative path starts with `packs/`.
6. File size matches.
7. Concurrent two place_pack different short_id/ts — both exist (no clobber).

Использовать `tempfile::TempDir` как den_root.

Команда:

```bash
cargo test -p raccpack-core den layout
```
