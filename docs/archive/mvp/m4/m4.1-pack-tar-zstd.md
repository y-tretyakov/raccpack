## 1. Цель этапа

Реализовать **упаковку дерева проекта** в архив **tar + zstd**:

- обход с `follow_links(false)` и SkipPolicy;
- **deny-list по имени** (те же/пересекающиеся правила, что filename secrets — не класть `.env`, keys, pem и т.п. в архив);
- запись архива во **временный файл** (staging path передаёт caller);
- **без** записи в финальный den layout (это M4.2);
- **без** facade `pack` и CLI (M4.3 / M4.4);
- content-deny (скан содержимого перед pack) — опционально/заготовка; полный deny content — можно добить в M4.3.

На выходе: низкоуровневый API `pack_tree → archive file`.

## 4. Deny-list по имени

### 4.1. Политика

Файл **не попадает в архив**, если:

1. `SkipPolicy.should_skip_dir` на любом предке (не заходим), или
2. basename матчится **pack-deny** patterns.

Pack-deny ≈ filename secret patterns с risk ≥ High (или отдельный флаг `deny_in_pack: true` на pattern).

Рекомендация MVP:

```rust
pub fn should_deny_file_in_pack(path: &Path) -> bool {
    match_filename(path)
        .map(|m| m.risk >= SensitiveRisk::High)
        .unwrap_or(false)
}
```

Дополнительно явный список hard-deny names (дублирует таблицу — лучше единый источник в `secrets/filename.rs`).

**Не** удалять исходные файлы — только omit из archive.

### 4.2. Content-deny (минимум / заготовка)

```rust
pub struct ContentDenyOptions {
    pub enabled: bool,
    pub min_risk: SensitiveRisk, // default Critical
}
```

Если enabled: для каждого кандидата на inclusion прогнать content markers (ограниченный read); при hit ≥ min_risk — omit + счётчик `skipped_secret_files`.

Полная интеграция может быть в M4.3; в M4.1 достаточно name-deny + hook/API flag.

## 5. API упаковки

```rust
use std::path::{Path, PathBuf};

#[derive(Debug, Clone)]
pub struct PackTreeOptions {
    pub policy: crate::scan::SkipPolicy,
    pub max_depth: usize,           // usually generous for pack (e.g. 64) or unlimited
    pub zstd_level: i32,            // default 3
    pub deny_name_secrets: bool,    // default true
    pub content_deny: ContentDenyOptions,
}

impl Default for PackTreeOptions {
    fn default() -> Self {
        Self {
            policy: SkipPolicy::default_scan(),
            max_depth: 64,
            zstd_level: 3,
            deny_name_secrets: true,
            content_deny: ContentDenyOptions {
                enabled: false, // name-only in pure M4.1; enable in M4.3 default true
                min_risk: SensitiveRisk::Critical,
            },
        }
    }
}

#[derive(Debug, Clone)]
pub struct PackTreeResult {
    /// Path of written archive (caller-provided destination).
    pub output: PathBuf,
    pub size_bytes: u64,
    pub file_count: usize,
    pub skipped_secret_files: usize,
    pub skipped_dir_names: usize, // optional stats
}

/// Pack `source` directory into `output` as tar+zstd.
/// `output` parent must exist; file is created/overwritten.
/// Never follows symlinks (files: store as symlink entry or skip — see below).
pub fn pack_tree(
    source: &Path,
    output: &Path,
    opts: &PackTreeOptions,
) -> Result<PackTreeResult, Error>;
```

### 5.1. Поведение symlink

| Тип | MVP поведение |
|-----|----------------|
| symlink → file | **не follow**; либо skip, либо tar symlink header (относительный target). Рекомендация: **skip** + optional counter, проще и безопаснее |
| symlink → dir | не follow (walk already false) |

Зафиксировать: **skip all symlinks** в pack MVP.

### 5.2. Алгоритм

```text
1. ensure source is dir
2. create output file (or tempfile then rename — caller may pass tempfile path)
3. zstd encoder wrapping tar Builder
4. walk source (follow_links false, policy, max_depth)
5. for each file:
     if deny_name → skipped_secret_files++
     else if content_deny hit → skipped_secret_files++
     else if symlink → skip
     else append to tar with path relative to source
6. finish tar + zstd
7. return stats (output metadata len)
```

Relative paths inside tar: **posix-style**, no absolute paths, no `..` escape.  
Root of archive = contents of `source`, not the folder name itself (или с top-level dirname — **выбрать одно**).

**Рекомендация:** entries вида `src/main.rs`, не `myproject/src/main.rs` (caller знает project name). Альтернатива: один top-level `project_slug/`. Для den layout удобнее **без** лишней обёртки или **с** slug — зафиксировать в rustdoc.  
Распространённый вариант: archive root = project root contents.

### 5.3. Атомарность

`pack_tree` пишет прямо в `output`. Атомарность (temp + rename) — ответственность facade M4.3 / den writer M4.2.

## 6. Ошибки

- source not found / not dir → `PathNotFound` / `NotADirectory`
- cannot create output → `Io`
- walk/read mid-pack → `Io` (partial file may remain; caller deletes on error)

## 7. Тесты (обязательные)

Fixture:

```text
proj/
  src/main.rs          # include
  .env                 # deny by name
  target/debug/x       # skip dir
  node_modules/a.js    # skip dir
  notes.txt            # include
  link -> /etc/passwd  # skip symlink
```

1. Archive contains `src/main.rs`, `notes.txt`.
2. Archive **does not** contain `.env`.
3. No paths under `target/` or `node_modules/`.
4. Symlink not followed / not present as external content.
5. `file_count` matches included files.
6. `skipped_secret_files >= 1` for `.env`.
7. Roundtrip: unpack (test-only) and compare set of relative paths.
8. Empty dir → valid empty-ish archive (or only dirs), no panic.
9. zstd level accepted.

Команда:

```bash
cargo test -p raccpack-core pack archive
```

Для unpack в тестах: `tar` + `zstd` decode или `tar` crate read mode.
