## 1. Цель этапа

Собрать **публичный use-case `pack`**:

- `PackOptions` / `PackResult` по facade-документу;
- уважение `RunMode::DryRun` vs `Commit`;
- staging → `pack_tree` → `place_pack` в den;
- progress `OperationKind::Pack`;
- опционально включить `deny_content_secrets`.

Без CLI (M4.4) и без полного raid.

---

## 2. Контекст (facade §7)

```rust
pub struct PackOptions {
    pub project: PathBuf,
    pub output_name: Option<String>,  // override artifact name; None → auto
    pub deny_content_secrets: bool,
    pub zstd_level: Option<u32>,
}

pub struct PackResult {
    pub source: PathBuf,
    pub output: PathBuf,       // final path (or expected path in DryRun)
    pub size_bytes: u64,
    pub file_count: usize,
    pub skipped_secret_files: usize,
    pub dry_run: bool,
}

pub fn pack(
    ctx: &AppContext,
    opts: &PackOptions,
    progress: &mut dyn ProgressSink,
) -> Result<PackResult>;
```

## 3. Алгоритм

```text
1. t0 = now
2. project = opts.project (absolute/normalized)
3. ensure project is dir
4. den = ctx.paths.den_dir
5. progress.emit(pack, 0%, "preparing")
6. slug = project_slug(project.file_name())
7. ts = utc_timestamp_now()
8. expected_rel = packs/yyyy/mm/{slug}__{ts}.tar.zst
9. expected_abs = den.join(expected_rel)

10. if ctx.mode.is_dry_run():
      // optional: estimate file_count via walk without writing
      progress.emit(100%, complete)
      return Ok(PackResult {
          source: project,
          output: expected_abs,
          size_bytes: 0, // or estimate
          file_count: 0, // or estimate
          skipped_secret_files: 0,
          dry_run: true,
      })

11. ensure_den(&den)?
12. short = short_id()
13. staging = staging_pack_path(&den, &short)
14. create_dir_all(staging.parent())
15. progress.emit(… "archiving")
16. tree_opts = PackTreeOptions {
      deny_name_secrets: true,
      content_deny: ContentDenyOptions {
          enabled: opts.deny_content_secrets,
          min_risk: Critical,
      },
      zstd_level: opts.zstd_level.unwrap_or(config default) as i32,
      …
   }
17. pack_tree(&project, &staging, &tree_opts)?
18. progress.emit(… "placing in den")
19. if let Some(custom) = &opts.output_name {
      // place under packs/…/custom or still use layout — document:
      // MVP: output_name replaces filename only, still under packs/yyyy/mm/
   }
20. placed = place_pack(PlacePackRequest {
      den_root: den,
      project_name: slug,
      source_archive: staging,
      timestamp: Some(ts),
   })?
21. cleanup empty staging dir
22. progress.emit(100%, complete)
23. Ok(PackResult {
      source: project,
      output: placed.absolute_path,
      size_bytes: placed.size_bytes,
      file_count: from pack_tree,
      skipped_secret_files: from pack_tree,
      dry_run: false,
   })
```

### DryRun invariants

- **Не** создавать файлы в `packs/`.
- **Не** создавать staging (или создать и сразу удалить — лучше не создавать).
- `output` = **ожидаемый** путь (для UX/JSON).

### Commit invariants

- Артефакт только под `den/packs/…`.
- Name-deny always on; content-deny по флагу (default **true** в facade Default для pack opts — см. RaidPackPhase; для standalone pack default true тоже).

## 5. Тесты (обязательные)

1. **DryRun:** no files created under den; result.dry_run=true; output path looks like packs/…/….tar.zst.
2. **Commit:** file exists at result.output; size > 0 for non-empty project; readable as zstd/tar.
3. `.env` in project → skipped_secret_files ≥ 1; archive open does not list `.env`.
4. `deny_content_secrets: true` + file with AKIA → skipped (if content deny implemented).
5. Progress phase_complete.
6. Invalid project path → Error.
7. den ensure creates version on first pack.

Команда:

```bash
cargo test -p raccpack-core pack facade
```

## 6. Ограничения и запреты

- Не stash/rinse/raid.
- DryRun не пишет packs/.
- Не raw secrets in PackResult (только counts).
- Не break tar path safety (`..`).
