# B1.2 TUI Sniff Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the TUI sniff screen showing project table with name, stack (flat), size, git status, and path. Support rescan, change root, navigation, and Enter to open dig.

**Architecture:** Thin UI layer over raccpack-core sniff. Worker thread runs core sniff asynchronously, sends progress/events via channel. UI renders project table with loading/error/empty states.

**Tech Stack:** ratatui 0.29, crossterm 0.28, raccpack-core (existing), dirs 6 for default den path.

```rust
pub enum AppEvent { Key, Resize, Quit, Worker(WorkerEvent) }
fn run_event_loop(app) {
    let (worker_tx, worker_rx) = mpsc::channel();
    let worker_sender = spawn_worker(worker_rx);
    // spawn event_reader
    loop {
        match ui_rx.recv_timeout(...) {
            Ok(AppEvent::Key) => { cmd = app.handle_key(); handle_app_command(cmd, &worker_sender, app); }
            Ok(AppEvent::Worker(e)) => handle_worker_event(e, app);
            ...
        }
        render(...)
    }
}
fn handle_app_command(Command::SniffRefresh, worker_tx, app) { send WorkerMsg::Sniff }
fn handle_worker_event(WorkerEvent::Progress, app) { app.sniff_state.progress = Some(...); set_loading(true); }
fn handle_worker_event(WorkerEvent::SniffDone(Ok(r)), app) { populate projects from report; }
fn handle_worker_event(WorkerEvent::SniffDone(Err(e)), app) { app.sniff_state.error = Some(...); }
```
