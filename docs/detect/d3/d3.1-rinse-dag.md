# D3.1 — `rinse` использует DAG: только релевантные поддеревья

**Зависимости:** D2, A2 rinse  
**Параллельность:** Dev + Test

---

## 1. Цель

В mode **composite_dag**:

- `target/` удаляется только под **Rust** scope paths
- `node_modules/` — только под **Node** scope
- `venv`/`.venv` — под Python scope
- и т.д. по strategy ↔ ecosystem mapping

В mode **priority_table**:

- текущее поведение A2: strategies по **всему** project root (без регрессий)

---

## 2. Mapping strategy → ecosystem (зафиксировать)

| StrategyId | Ecosystems / scopes |
|------------|---------------------|
| rust | rust |
| node | node |
| python | python |
| jvm | jvm |
| go | go |
| generic | project root only (careful) или all scopes |

`find_trash_dirs` принимает optional `scopes: &[(StrategyId, PathBuf)]` или filter after detect.
