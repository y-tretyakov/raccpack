# D3.2 — `sniff` вывод дерева / DAG

**Зависимости:** D2.3, D1.3

---

## 1. Цель

```bash
racc sniff --root PATH --detect-mode priority_table
racc sniff --root PATH --detect-mode composite_dag
racc sniff --root PATH --detect-mode dag --json
racc sniff --root PATH --detect-mode dag -v
```

### JSON

```json
{
  "report": {
    "projects": [
      {
        "name": "mono",
        "stack": { "language": "rust", "frameworks": [], "markers": ["Cargo.toml"] },
        "stack_tree": {
          "detection": { "ecosystem": "rust", "scope": "…", "confidence": 0.9 },
          "children": [
            {
              "detection": { "ecosystem": "node", "scope": "…/web", "frameworks": ["next"] },
              "children": []
            }
          ]
        }
      }
    ]
  }
}
```

### Human (dag mode)

Indented tree or secondary block under project, e.g.:

```text
mono  rust+node  1.2GiB  git  /path/mono
  ├─ rust  (.)
  └─ node  (web)  frameworks: next
```

priority_table human: **unchanged** table.

---

## 2. Модульность

```text
cli/output.rs or output_sniff.rs   # tree renderer
app/sniff.rs                       # fill stack_tree when mode=dag
```

---

## 3. Примеры CLI

```bash
# Classic
racc sniff --root ~/DEV/PROJS

# DAG
racc sniff --root ~/DEV/MONOREPO --detect-mode dag

# JSON for scripts
racc sniff --root ~/DEV/MONOREPO --detect-mode composite_dag --json \
  | jq '.report.projects[] | {name, stack_tree}'

# Config-driven
# config.toml: [detect] mode = "composite_dag"
racc sniff --root ~/DEV/MONOREPO
```
