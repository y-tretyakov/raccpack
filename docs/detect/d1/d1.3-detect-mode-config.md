# D1.3 — Config / CLI `detect.mode`

**Зависимости:** D1.1–D1.2

---

## 1. Цель

```toml
[detect]
mode = "priority_table"   # default until D2 stable in production use
# mode = "composite_dag"
```

```rust
pub enum DetectMode {
    PriorityTable,  // default
    CompositeDag,
}
```

CLI:

```bash
racc sniff --root PATH
racc sniff --root PATH --detect-mode priority_table
racc sniff --root PATH --detect-mode composite_dag
racc sniff --root PATH --detect-mode dag          # alias → composite_dag
racc sniff --root PATH --detect-mode dag --json
```

Unknown mode → Error with suggestion.

`AppContext` / sniff options carry mode (from config + CLI override).

---

## 2. Модульность

```text
src/config/          # DetectConfig section
src/app/sniff.rs     # honor mode
cli: SniffArgs --detect-mode
```

---

## 3. Примеры CLI

```bash
# Default = priority_table (unchanged UX)
racc sniff --root ~/DEV/PROJS

# Explicit DAG (after D2)
racc sniff --root ~/DEV/PROJS --detect-mode composite_dag --json \
  | jq '.report.projects[] | {name, stack, stack_tree}'

# Alias
racc sniff --root ~/DEV/PROJS --detect-mode dag -v
```

## 5. Реализация (0.3.3 / PR #94)

`DetectMode` в `detect/mode.rs`; секция `[detect]` в конфиге (default, старые TOML валидны); unknown TOML → `ConfigError::UnknownDetectMode` + hint; CLI `--detect-mode` (ValueEnum, alias `dag`, unknown → clap possible values). **composite_dag до D2.x — явная ошибка** `Error::DetectPipelineUnavailable` (fail до IO), не тихий fallback. Кэш-fingerprint различает режимы; default-ключ прежний.
