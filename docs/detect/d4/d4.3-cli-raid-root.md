# D4.3 — CLI: `racc raid --root`

**Зависимости:** D4.2

---

## 1. CLI

```text
racc raid --project <PATH>   # existing single
racc raid --root <PATH>      # NEW batch

# shared
          [--den <PATH>]
          [--yes] [--dry-run] [--json]
          [--no-stash] [--no-rinse] [--no-pack]
          [--min-risk …] [--keep-sources] [--no-content-deny]
          [--fail-fast]              # OrchestrationMode::FailFast *inside* each raid

# batch-only
          [--only <SUBSTR>]…         # filter project name/path
          [--limit <N>]
          [--stop-on-error]          # stop batch after first failed project
```

Правила clap:

- required: **one of** `--project` / `--root`
- conflicts_with between them

Exit codes:

| Code | When |
|------|------|
| 0 | batch success (all run projects ok) or 0 projects |
| 1 | any project failed / hard Err |

Passphrase: once if any project will Commit with stash enabled.

---

## 2. Примеры

```bash
# План по всем проектам в корне
racc raid --root ~/DEV/PROJS --den ~/.raccpack/den

# Commit всех
export RACCPACK_PASSPHRASE='…'
racc raid --root ~/DEV/PROJS --den ~/.raccpack/den --yes

# Только имена с "api"
racc raid --root ~/DEV/PROJS --den ~/.raccpack/den --yes --only api

# Первые 3 (отладка)
racc raid --root ~/DEV/PROJS --den ~/.raccpack/den --limit 3

# JSON сводка
racc raid --root ~/DEV/PROJS --den ~/.raccpack/den --yes --json \
  | jq '{success, projects_total, results: [.results[] | {project_name, success: .outcome}]}'

# Остановить batch на первой ошибке
racc raid --root ~/DEV/PROJS --den ~/.raccpack/den --yes --stop-on-error

# Один проект — как раньше
racc raid --project ~/DEV/PROJS/my-api --den ~/.raccpack/den --yes
```

Human output (sketch):

```text
→ [1/4] my-api
  → stash: …
  → pack: …
→ [2/4] webapp
  …
Batch: 3 ok, 1 failed, 0 skipped
Failed
```
