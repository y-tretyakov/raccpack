## 1. Цель

```rust
pub struct RaidBatchOptions {
    pub root: PathBuf,
    pub den_dir: PathBuf,
    pub raid: RaidOptions,       // mode, phases, min_risk, … shared
    pub only: Vec<String>,       // optional filters
    pub limit: Option<usize>,
    pub stop_on_project_failure: bool,  // batch fail-fast
}

pub struct RaidBatchResult {
    pub root: PathBuf,
    pub dry_run: bool,
    pub projects_total: usize,
    pub projects_run: usize,
    pub results: Vec<RaidBatchItem>,
    pub success: bool,  // all run items success
}

pub struct RaidBatchItem {
    pub project_path: PathBuf,
    pub project_name: String,
    pub outcome: RaidBatchOutcome,
}

pub enum RaidBatchOutcome {
    Raided(RaidResult),
    Skipped { reason: String },
    Error { message: String },  // discover/precondition before raid()
}

pub fn raid_batch(
    opts: &RaidBatchOptions,
    identity: Option<&AgeIdentity>,
    progress: &mut dyn ProgressSink,
) -> Result<RaidBatchResult, Error>;
```

### Алгоритм

1. `sniff`-equivalent discover under `root` (respect skip policy, max_depth, detect.mode).
2. Filter `only`, apply `limit`.
3. For each project path (sorted):
   - emit batch progress (`OperationKind::RaidBatch` or reuse Raid with project label)
   - call existing `raid()` with that `project_path` + shared `RaidOptions` / identity
   - push item; if `!item.success && stop_on_project_failure` → break
4. `success = all Raided items have success==true` (skipped don't fail batch).

**Не** дублировать stash/rinse/pack логику — только цикл + aggregate.
