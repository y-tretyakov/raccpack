# B4.1 — `racc den` list / gc

**Зависимости:** den layout, manifests

---

## 1. Цель

```bash
racc den list --den PATH
racc den list --den PATH --json

racc den gc --den PATH --older-than 7d
racc den gc --den PATH --older-than 7d --yes
racc den gc --den PATH --older-than 24h --yes
```

- **list:** packs / secrets / manifests summary
- **gc:** only `staging/` older than N; dry-run default
- **gc never** deletes secrets/packs/manifests
