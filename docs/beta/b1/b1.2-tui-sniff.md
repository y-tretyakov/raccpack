# B1.2 — Экран sniff

**Зависимости:** B1.1, core `sniff` (Detect v2: optional stack_tree)

---

## 1. Цель

Таблица проектов: name, stack (flat), size, git, path.  
При DAG mode — дерево/вложенность если `stack_tree` есть.  
Rescan, change root, progress via worker thread.

---

## 2. Модульность

```text
src/ui/screens/sniff.rs
src/worker.rs          # run_sniff → channel
```

---

## 3. Keys

| Key | Action |
|-----|--------|
| `r` | force_refresh |
| `o` | change scan root |
| `j`/`k` | select |
| `Enter` | open dig |
