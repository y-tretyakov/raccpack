# B1.5 — Write workflows: stash, rinse, pack + Preview/Confirm

**TUI-spec:** Phase 4 · Safety levels

---

## 1. Action levels

| Level | Ops | UX |
|-------|-----|-----|
| WRITE | pack, stash (no remove) | Preview → Enter |
| DESTRUCTIVE | rinse, stash+remove_sources | Preview → type `yes` or phrase |

Never: Select → Enter → delete.

---

## 2. Preview

Semantic plan (prefer core **DryRun** results when available):

```text
STASH  findings: N · source removal: no|yes
RINSE  candidates / estimated (label estimates if not from core)
PACK   output name
[Enter] execute  [Esc] cancel
```

## 3. Passphrase

- Secure prompt widget; never log value.
- Prefer zeroize buffers; same policy as CLI.

## 4. After success

2. Esc / Ctrl+C in confirm ≠ confirm.
3. No secret in render buffer.
4. Partial failure not shown as success.
