# B1.1 — Foundation: crate, TerminalGuard, event loop, state

**TUI-spec:** Phase 0 · §0 v4 (core verified)  
**Параллельность:** Dev + Test

---

## 1. Цель

1. Workspace member `crates/raccpack-tui`.
2. Depends **only** on `raccpack-core` (+ ratatui, crossterm, tokio, serde, tracing).
3. `TerminalGuard` + panic hook → restore terminal always.
4. Event loop: input / tick / progress channel → `update` → `view` (pure).
5. Minimal `App` state machine: Boot → Ready (empty shell ok).

---

## 2. Модульность

```text
crates/raccpack-tui/
  Cargo.toml
  src/main.rs
  src/app.rs          # App, AppScreen
  src/event.rs        # AppEvent

  src/job.rs          # JobRunner / spawn_blocking seam

  src/widgets/mod.rs
```

Entry:

```bash
racc tui
# optional alias if trivial: racc --tui
```

Wire as CLI subcommand without changing other commands' semantics.

## 3. Core facts (must honor)

| Fact | Implication |
|------|-------------|
| Facades **sync** | `tokio::task::spawn_blocking` for sniff/dig/raid/… |
| No cancellation API | no fake cooperative cancel |
| ProgressSink | channel → `AppEvent::Progress` |

```rust
pub enum AppScreen { Boot, InitWizard, ConfigError(String), Ready }
pub enum Cmd { None, StartOperation(...), Quit, PersistPrefs }
```
