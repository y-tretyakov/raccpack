# B1.6 — Raid as Operation (pipeline, Atomic/FailFast)

**TUI-spec:** Phase 5 · v4 §0.5–0.8

---

## 1. Цель

Raid **не** отдельный ViewId-centric app section — workflow:

```text
Select project → Preview (DryRun) → Confirm → Running phases → Result
```

Pipeline display from core events:

```text
STASH  ✓/●/○
RINSE  …
PACK   …
MOVE   …   (commit)
```

Show mode badge: **ATOMIC** (default) | **FAIL-FAST**.

### Result honesty

| Core | UI |
|------|-----|
| `success` | Success |
| `rolled_back` | Rolled back + warnings |
| `success: false` stages skipped | Partial / Failed — **not** “success with warnings” only |
| FailFast orphans possible | Text: artifacts may remain |

Do not promise rollback when mode is FailFast.

---

## 2. Progress

Raid emits **completion-per-phase** (no fake continuous file progress).  
Use `overall_percent`, `phase`, `message` from `ProgressEvent`.

---

## 3. Confirm

DESTRUCTIVE: explicit `yes` or `raid <project>`.

---

## 4. Keys (context)

| Key | Action |
|-----|--------|
| `r` | raid preview for selection |
| `Enter` | advance confirm / execute |
| `Esc` | cancel preview/confirm or leave running view |
| `K` | keep sources (map to options) |
| `S` | skip stash phase |
