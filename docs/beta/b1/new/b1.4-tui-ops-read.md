## 1. Цель

1. `StartSniff` / `StartDig` → `JobRunner` → core `sniff` / `dig`.
2. `TuiProgressSink` implements `ProgressSink` → `AppEvent::Progress`.
3. **Operations** view: RUNNING + HISTORY.
4. Operation detail shows phase from **real** events only (no invented file-level %).

### Operation state

```text
Preparing → (optional Preview for analyze?) → Running → Completed(Success|Failed|…)
```

For sniff/dig: Enter runs; no destructive confirm.

---

## 2. Cancellation UX (honest)

Core **has no** cancel API (v4 §0.4):

```text
[Esc] Leave operation view
```

Do **not** claim “operation cancelled and rolled back”.
