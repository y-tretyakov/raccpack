# B1.5 — TUI ephemeral reveal modal

**Зависимости:** B1.3, **B3.4** EphemeralSecret

---

## 1. Цель

Opt-in reveal selected finding: confirm → modal shows raw once → close → zeroize.  
Never store raw in App state.

---

## 2. Keys

| Key | Action |
|-----|--------|
| `v` | request reveal (confirm first) |
| `Esc` | close + wipe |

---

## 3. DoD

- [ ] Uses core EphemeralSecret / reveal API
- [ ] No raw in logs
- [ ] Modal closed → memory cleared
- [ ] Default: masked only
