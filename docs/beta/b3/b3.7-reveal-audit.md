# B3.7 — Optional audit-log факта reveal

---

## 1. Цель

Логировать **факт** reveal (timestamp, path, risk) **без** значения.

```toml
[security]
reveal_audit = false
reveal_audit_path = "~/.local/state/raccpack/reveal-audit.log"
```

Default: off.

---

## 2. DoD

- [ ] Audit line has no secret body
- [ ] Works for CLI/TUI/Desktop when enabled
