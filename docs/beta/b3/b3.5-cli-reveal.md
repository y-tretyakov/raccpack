# B3.5 — CLI interactive reveal

**Зависимости:** B3.4

---

## 1. Цель

```bash
racc reveal --project PATH --file .env
# Confirm: type REVEAL
# prints value once to TTY

racc reveal --project PATH --path .env --index 0
```

- Explicit confirm / flag
- No reveal value in `--json` mode (Error if requested)
- Not logged at -vv

---

## 2. Примеры CLI

```bash
racc dig --project ~/DEV/PROJS/my-api
racc reveal --project ~/DEV/PROJS/my-api --file .env

# Must not leak to logs
racc reveal --project PATH --file .env -vv 2>&1 | tee /tmp/r.log
# secret value absent from /tmp/r.log
```
