# TUI (терминальный интерфейс)

::: info
TUI строится в Beta (0.5.x). По состоянию на **0.4.2** работает **экран sniff** (таблица проектов, неблокирующий worker); экраны dig/raid и reveal-модалка планируются.
:::

## Что это

`racc-tui` — интерактивный терминальный интерфейс на базе Ratatui. Позволяет работать с проектами и секретами без запоминания команд: навигация, таблица проектов, подтверждения.

## Экран sniff (доступен с 0.4.2)

- Выводит проекты из корня сканирования в таблице: имя, язык, фреймворки, размер, признак git-репозитория.
- Запускает `sniff` в фоновом worker-потоке, поэтому UI остаётся отзывчивым (показывается индикатор прогресса) во время сканирования.
- Навигация: `j`/`k` (или стрелки) — выбор строки; `r` — обновить; `o` — смена корня сканирования (зарезервирована, ещё не реализована); `Enter` — открыть проект (dig — планируется).

## Целевые возможности

- **Экран dig** — находки секретов с фильтрами по уровню риска и маскированными деталями.
- **Подтверждение raid** — мастер, в котором видно, что произойдёт на каждой фазе (stash → rinse → pack), с интерактивным прогрессом.
- **Dry-run** — режим, в котором видны все изменения до их применения.

## Как это будет работать

TUI использует тот же публичный контракт ядра, что и CLI, поэтому результаты и политики (риски, маскирование, dry-run) одинаковы во всех интерфейсах.

```
нажатие клавиши  →  состояние экрана TUI  →  вызов facade
                 ←  события прогресса + отчёт ←  ядро
                 →  обновление панелей
```

## Прогресс длинных операций

Длинные операции (глубокий `dig`, полный `raid`) шлют события прогресса: фаза, процент, сообщение. TUI перерисовывает экран по каждому событию, не блокируя интерфейс.

## Визуальная система (design tokens)

Цветовая семантика TUI задаётся design-токенами в формате **DTCG** (`docs/design-tokens/raccpack.tokens.json`) — единый источник и для TUI, и для будущего Desktop. Экран использует semantic-имена (`bg`, `fg`, `accent`, `muted`, `danger`, `selection` и т.д.), а размеры (ширина сайдбара, высота панелей) — в **терминальных клетках**. Это значит, что «перекрасить» продукт можно правкой одного файла, не трогая виджеты.
